BFS & DFS 廣度與深度優先搜尋queue 一層一層擴散，stack 一條路走到底

Ch6 Graphs 難度 BFS DFS queue stack spanning tree

為什麼要走訪圖

很多問題拿到手，第一步都是「從某個點出發，看看能走到哪些點」：地圖上兩個城市有沒有路相通、社群網路裡某人的朋友的朋友有誰、迷宮從入口走得到出口嗎、網路上的封包最少要轉幾次。把這些東西畫成 Graph（圖）：頂點代表城市或人，邊代表道路或朋友關係，問題就變成有系統地把圖上每個能到的頂點拜訪一次，這就是 Graph Traversal（圖的走訪）。

二元樹的走訪在二元樹走訪那一頁已經講過，圖的走訪是它的推廣，但圖比樹麻煩三件事：

  • 沒有根：圖沒有天生的起點，題目要指定一個 起點 s，不同起點得到的順序不同。
  • 有環（cycle）：樹從父節點往下走永遠不會繞回來，圖卻可能 0 → 1 → 4 → 3 → 0 繞一圈回到原點。如果不記錄「誰已經拜訪過」，就會無限繞圈。所以每個圖走訪演算法都有一個 visited[] 陣列。
  • 不一定連通：從 s 出發可能根本走不到某些頂點，要把整張圖都走完，得在外面再包一層迴圈，換新的起點繼續走（後面講連通元件時會用到）。

最基本的走訪方式有兩種，差別在於「發現了好幾個新頂點，先處理哪一個」：

  • Breadth-First Search（BFS，廣度優先搜尋）：先把離起點近的全部處理完，再往外一圈，像水波一樣擴散。用 queue 實現「先發現的先處理」。
  • Depth-First Search（DFS，深度優先搜尋）：有路就往深處走，走到死路才退回上一個岔路口換另一條，像走迷宮時「右手扶牆」。用 stack（或遞迴）實現「最後發現的先處理」。

本頁的範例圖與表示法

圖在程式裡常見兩種存法。Adjacency Matrix（相鄰矩陣）用一個 n × n 的二維陣列，adj[v][w] = 1 表示 v 和 w 之間有邊；Adjacency List（相鄰串列）則替每個頂點準備一條鏈結串列，串起它所有的相鄰點。無向圖的一條邊 (u, v) 在兩邊都要記：u 的串列裡有 v，v 的串列裡也有 u，所以 10 條邊的圖會有 20 個串列節點。

看程式碼：圖的宣告與建立（相鄰串列＋相鄰矩陣）
宣告與 addEdge()
typedef struct Node {
  int v;                                 /* 相鄰的頂點編號 */
  struct Node *next;
} Node;

int n;                                   /* 頂點數，編號 0 ~ n-1 */
Node *list[MAXV];                        /* 相鄰串列：list[v] 是 v 的所有相鄰點 */
int adj[MAXV][MAXV];                     /* 相鄰矩陣：adj[v][w] = 1 表示有邊 (v, w) */
int visited[MAXV];
int parent[MAXV];                        /* 生成樹上的父節點，起點是 -1 */
int dist[MAXV];                          /* BFS：起點到 v 的最少邊數 */
int d[MAXV], f[MAXV], timer;             /* DFS：發現時間、完成時間 */

void addEdge(int u, int v) {             /* 無向圖：兩邊都要記 */
  adj[u][v] = adj[v][u] = 1;
  insertSorted(u, v);
  insertSorted(v, u);
}

BFS：一層一層往外擴

BFS 的想法是：先拜訪起點 s，再拜訪所有「離 s 一條邊」的頂點，接著是「離 s 兩條邊」的頂點……一層一層往外。要做到「同一層全部處理完才換下一層」，只要用 queue（先進先出）排隊就好：第 k 層的頂點一定比第 k + 1 層的頂點早進 queue，所以也一定比較早出來。這和二元樹的層序走訪是同一個招式，差別只在圖要多一個 visited 防止重複。

  1. 把起點 s 標記為 visited，放進 queue。
  2. 只要 queue 不空：從前端取出一個頂點 v 並拜訪它。
  3. 依序看 v 的每個相鄰點 w：如果 w 還沒 visited，就立刻標記、記下 parent[w] = v 和 dist[w] = dist[v] + 1，放到 queue 尾端。

放進 queue 的那一刻就要標記 visited，不要等到取出時才標。否則一個頂點可能被好幾個鄰居各放一次，queue 裡出現重複，輸出順序也會跟著錯。

為什麼 BFS 能求最短路徑邊數

queue 裡的頂點，dist 永遠是「前面一段是 k、後面一段是 k + 1」，不會出現 k + 2。所以頂點是依照 dist 由小到大被取出的。一個頂點 w 第一次被發現時，發現它的 v 是「所有鄰居裡最早被取出的」，也就是 dist 最小的鄰居，因此 dist[w] = dist[v] + 1 就是最少邊數。這只在每條邊的成本都一樣（無權圖）時成立；邊有不同權重時要用 Dijkstra 演算法。

看程式碼：bfs()（相鄰串列／相鄰矩陣）
bfs()：相鄰串列，O(V + E)
void bfs(int s) {
  int queue[MAXV], front = 0, rear = 0;
  visited[s] = 1;                        /* 起點先標記再放進 queue */
  dist[s] = 0;
  queue[rear++] = s;
  while (front < rear) {
    int v = queue[front++];              /* 取出 queue 前端 */
    printf("%d ", v);
    for (Node *p = list[v]; p != NULL; p = p->next) {
      int w = p->v;
      if (!visited[w]) {                 /* 第一次看到 w：標記、記父節點、放進 queue */
        visited[w] = 1;
        dist[w] = dist[v] + 1;
        parent[w] = v;                   /* (v, w) 是 BFS 生成樹的樹邊 */
        queue[rear++] = w;
      }
    }
  }
}
bfsMatrix()：相鄰矩陣，O(V²)
void bfsMatrix(int s) {
  int queue[MAXV], front = 0, rear = 0;
  visited[s] = 1;
  queue[rear++] = s;
  while (front < rear) {
    int v = queue[front++];
    printf("%d ", v);
    for (int w = 0; w < n; w++)          /* 整列 n 格都要看：每個頂點 O(n) */
      if (adj[v][w] && !visited[w]) {
        visited[w] = 1;
        queue[rear++] = w;
      }
  }
}

DFS：一條路走到底再回頭

DFS 的規則只有一句：站在 v，找一個還沒拜訪的相鄰點 w，馬上走過去；在 w 也照做；直到某個頂點的相鄰點全部都拜訪過了（死路），才退回上一個頂點，看它還有沒有別條路。這種「先處理最後發現的」正是 stack 的 LIFO，最簡潔的寫法是遞迴：系統的 call stack 自動幫我們記住退回去的路。

  1. dfs(v)：標記 v 為 visited 並拜訪它。
  2. 依序看 v 的每個相鄰點 w，遇到還沒 visited 的就呼叫 dfs(w)；它回來之後再繼續看下一個相鄰點。
  3. 所有相鄰點都看完，dfs(v) 結束，回到呼叫它的頂點。

發現時間與完成時間

給 DFS 加一個計時器：進入 dfs(v) 時記下 Discovery Time（發現時間） d[v]，離開時記下 Finish Time（完成時間） f[v]。因為遞迴是「進去 → 處理所有子孫 → 出來」，所以子孫的 [d, f] 區間一定完整包在祖先的區間裡，兩個頂點的區間不是包含就是完全不重疊，這叫括號定理。之後的拓樸排序、強連通元件都靠完成時間。

看程式碼：dfs()（遞迴，相鄰串列／相鄰矩陣）
dfs()：遞迴，記錄發現與完成時間
void dfs(int v) {
  visited[v] = 1;
  d[v] = ++timer;                        /* 發現時間 */
  printf("%d ", v);
  for (Node *p = list[v]; p != NULL; p = p->next)
    if (!visited[p->v]) {
      parent[p->v] = v;                  /* (v, w) 是 DFS 生成樹的樹邊 */
      dfs(p->v);
    }
  f[v] = ++timer;                        /* 完成時間：v 的相鄰點都處理完了 */
}
dfsMatrix()：遞迴，相鄰矩陣
void dfsMatrix(int v) {
  visited[v] = 1;
  printf("%d ", v);
  for (int w = 0; w < n; w++)            /* 整列 n 格都要看：每個頂點 O(n) */
    if (adj[v][w] && !visited[w])
      dfsMatrix(w);
}

不用遞迴：自己準備 stack

遞迴太深怕 stack overflow，或考題要求非遞迴時，就自己用 stack，概念和二元樹的非遞迴走訪相同。常見兩種寫法：

  • 看頂端、走一步（預設頁籤）：看 stack 頂端的 v，找它下一個未拜訪的相鄰點 w；有就拜訪 w 並 push，沒有就 pop 退回。stack 裡永遠是「從起點到目前位置的路徑」，和遞迴的呼叫堆疊一模一樣，最多 V 個。用 cur[v] 記住 v 的串列看到哪裡，總共仍是 O(V + E)。
  • pop 出來才標記、相鄰點全部 push：寫起來短，但同一個頂點可能被不同鄰居 push 好幾次，stack 最多要 2E + 1 格；而且要由大到小 push，編號小的才會先被 pop，順序才會和遞迴版一樣。
看程式碼：DFS 的 stack 寫法（看頂端版／全部 push 版）
dfsStack()：stack 內容就是目前路徑
void dfsStack(int s) {
  int stack[MAXV], top = -1;
  Node *cur[MAXV];                       /* cur[v]：v 的串列下一個要檢查的位置 */
  for (int i = 0; i < n; i++) cur[i] = list[i];
  visited[s] = 1;
  printf("%d ", s);
  stack[++top] = s;
  while (top != -1) {
    int v = stack[top];                  /* 看 stack 頂端，先不 pop */
    while (cur[v] != NULL && visited[cur[v]->v])
      cur[v] = cur[v]->next;             /* 跳過已經拜訪過的相鄰點 */
    if (cur[v] == NULL) {                /* v 沒有路可走了：pop，退回上一個頂點 */
      top--;
      continue;
    }
    int w = cur[v]->v;
    visited[w] = 1;
    parent[w] = v;
    printf("%d ", w);
    stack[++top] = w;                    /* 往更深的 w 走 */
  }
}
dfsPushAll()：pop 才標記，相鄰點由大到小 push
void dfsPushAll(int s) {
  int stack[MAXV * MAXV], top = -1;      /* 最多 push 2E + 1 次，不是 V 次 */
  stack[++top] = s;
  while (top != -1) {
    int v = stack[top--];
    if (visited[v]) continue;            /* 已經拜訪過的舊紀錄，直接丟掉 */
    visited[v] = 1;
    printf("%d ", v);
    for (int w = n - 1; w >= 0; w--)     /* 由大到小 push，編號小的才會先被 pop */
      if (adj[v][w] && !visited[w])
        stack[++top] = w;
  }
}

範例圖用三種 DFS 寫法（遞迴、看頂端版、全部 push 版）跑出來都是 0 1 2 5 4 3 6 7（已用程式驗證）。

動手操作

在第一個輸入框用「頂點-頂點」輸入無向圖的邊（用空白隔開，頂點編號 0～9、最多 20 條邊），第二個輸入框是起點，再選 BFS、DFS（遞迴）或 DFS（stack）。相鄰點一律由小到大。畫面下方會顯示 queue、呼叫堆疊或 stack 的內容與目前的走訪順序；綠色的邊是生成樹的樹邊；BFS 時頂點下方是 dist，遞迴 DFS 時是「發現 / 完成時間」。按「非連通圖」可以看到從 0 出發走不到其他連通元件。

BFS 樹與 DFS 樹

走訪時每個頂點（起點除外）都是被某一條邊「第一次發現」的，把這些邊 (parent[w], w) 收集起來，就得到一棵包含所有可到達頂點的樹，稱為 Spanning Tree（生成樹）：BFS 得到 BFS 樹，DFS 得到 DFS 樹。連通圖有 V 個頂點，生成樹一定剛好有 V − 1 條邊（範例圖是 8 − 1 = 7 條），剩下的 E − V + 1 條（範例圖 10 − 7 = 3 條）是非樹邊。

兩棵樹的非樹邊有各自的性質，考題很愛問：

  • BFS 樹：樹上從根到 v 的路徑就是一條最短路徑。非樹邊連接的兩個頂點，層數相差最多 1（同一層或相鄰層），不可能跨兩層，否則深的那個早就被淺的那個發現了。圖 2(a) 的非樹邊 (3,4)、(4,5)、(6,7)，都在相鄰層或同一層。
  • DFS 樹（無向圖）：每條非樹邊都連接一個頂點和它的祖先，叫 Back Edge（回邊）；不會連到旁支。圖 2(b) 的 (0,3)、(1,4)、(5,7) 都是從子孫連回祖先。這個性質是找關節點（articulation point）的基礎。

印出最短路徑

BFS 記下的 parent[] 就是一條條「往回指」的路：從終點沿 parent 一路走回起點，再倒過來印出。範例圖 0 到 7 的路徑是 7 → 5 → 2 → 1 → 0，倒過來就是 0 1 2 5 7，共 4 條邊，和 dist[7] = 4 一致。

看程式碼：printPath()：沿著 parent 印出路徑
printPath()
void printPath(int v) {                  /* 沿著 parent 回推起點，再倒著印出來 */
  if (parent[v] != -1) printPath(parent[v]);
  printf("%d ", v);
}

走訪順序由相鄰點的順序決定

BFS、DFS 都說「依序看 v 的相鄰點」，可是「依序」是什麼順序？演算法本身沒有規定，取決於相鄰串列裡的排列（矩陣版則固定是 w = 0, 1, …, n−1，也就是編號由小到大）。所以同一張圖、同一個起點，可能有很多種合法的 BFS 或 DFS 順序。考題為了讓答案唯一，通常會寫「相鄰點依編號（或字母）由小到大拜訪」；沒寫的題目則可能考「下列何者不可能是 DFS 順序」。

最容易中招的是用程式建圖的題目：如果 addEdge 把新節點插在串列前端（O(1)，很多程式這樣寫），那串列順序會和邊的輸入順序相反。題目給的是程式碼與邊的輸入順序時，一定要先畫出真正的串列，再開始追蹤。

看程式碼：建串列（依序插入／插在前端）
insertSorted()：保持由小到大
void insertSorted(int v, int w) {
  Node **pp = &list[v];
  while (*pp != NULL && (*pp)->v < w) pp = &(*pp)->next;
  Node *p = malloc(sizeof(Node));
  p->v = w;
  p->next = *pp;
  *pp = p;
}
insertFront()：順序會反過來
void insertFront(int v, int w) {         /* 對照用：插在串列前端，相鄰點順序會反過來 */
  Node *p = malloc(sizeof(Node));
  p->v = w;
  p->next = list[v];
  list[v] = p;
}

判斷一個序列是不是合法的 DFS 順序

手動模擬一個「路徑 stack」：每讀到下一個頂點 x，它必須是 stack 頂端的鄰居；如果不是，代表頂端已經沒路了才能退回，所以先檢查頂端是不是真的沒有未拜訪的鄰居，是才 pop 再比對下一層。只要遇到「頂端還有未拜訪的鄰居，序列卻跳去別的地方」，這個序列就不合法。BFS 則檢查：每個頂點被發現的先後，必須和「發現它的那個頂點」被取出的先後一致。

時間複雜度：O(V + E) 與 O(V²)

不管 BFS 還是 DFS，每個頂點只會被標記、進出 queue（或遞迴）一次，花費 O(V)。真正的差別在「找相鄰點」：

  • 相鄰串列：處理頂點 v 時走過它的串列，長度是 deg(v)。所有頂點加起來是 Σ deg(v) = 2E（每條無向邊在兩條串列各出現一次），所以總共 O(V + E)。
  • 相鄰矩陣：要找 v 的相鄰點，得把第 v 列 n 格全部看一遍，不管 v 實際上有幾個鄰居。V 個頂點各看 V 格，總共 O(V²)。
表示法BFS / DFS 時間空間適合
相鄰串列O(V + E)O(V + E)稀疏圖（E 遠小於 V²），實務上大部分的圖
相鄰矩陣O(V²)O(V²)稠密圖、需要 O(1) 判斷「v、w 有沒有邊」

拿數字感受一下：1000 個頂點、3000 條邊的稀疏圖，串列版大約檢查 1000 + 2 × 3000 = 7000 次，矩陣版要看 1000² = 1,000,000 格，差了約 140 倍。反過來，如果是完全圖（E = V(V − 1)/2），V + E 本身就是 Θ(V²)，兩種表示法就一樣快了。

額外空間方面：visited、parent 各 O(V)。BFS 的 queue 最多同時放 O(V) 個頂點（例如星狀圖，起點一次放進 V − 1 個）；DFS 的遞迴深度最多 O(V)（例如一條長鏈，要深入 V 層）。

一句話記：走訪 = 每個點一次 + 每條邊兩次。用串列，邊數直接算進去；用矩陣，每個點都要掃一整列，所以是 V × V。

應用：連通元件

無向圖中，彼此能互相走到的頂點組成一個 Connected Component（連通元件）。從 s 做一次 BFS 或 DFS，拜訪到的頂點剛好就是 s 所在的那一個連通元件。要找出所有元件，就從 0 到 n − 1 掃一遍：遇到還沒 visited 的頂點，就從它開始做一次走訪，每做一次就是一個新元件。

以「非連通圖」範例（邊 0-2 2-4 4-0 1-5 3-6 6-7 3-7）來說：從 0 走到 {0, 2, 4}；掃到 1 時它還沒拜訪，走到 {1, 5}；掃到 3 時走到 {3, 6, 7}。共 3 個連通元件（已用程式驗證）。雖然外層迴圈呼叫了好幾次 dfs，但每個頂點與每條邊仍只處理一次，總時間仍是 O(V + E)。

每個元件各得到一棵生成樹，合起來稱為 Spanning Forest（生成樹林）。V 個頂點、k 個連通元件時，樹林的邊數是 V − k（每棵樹少一條），這個公式在計算題裡很好用。

看程式碼：components()：數連通元件
components()
int components(void) {
  int k = 0;
  resetVisited();
  for (int v = 0; v < n; v++)
    if (!visited[v]) {                   /* 還沒被走到的點：屬於一個新的連通元件 */
      printf("元件 %d：", ++k);
      dfs(v);
      printf("\n");
    }
  return k;
}

BFS 與 DFS 比較

項目BFSDFS
輔助結構queuestack（或遞迴）
探索方式由近到遠，一層一層一條路走到底，死路再回頭
何時標記 visited放進 queue 時進入 dfs(v) 時
時間（串列／矩陣）O(V + E) ／ O(V²)O(V + E) ／ O(V²)
生成樹形狀寬而矮，根到每點是最短路徑窄而深，非樹邊都是回邊
典型應用無權圖最短路徑、依層處理、二分圖判斷連通性、找環、拓樸排序、關節點、強連通元件、迷宮與回溯

兩者都能判斷連通性、數連通元件、找生成樹，這些用哪個都行。需要「最少步數」時選 BFS；需要「祖先 / 子孫關係」或完成時間時選 DFS。另外 DFS 的遞迴寫法程式最短，但圖很大（例如百萬個頂點的一條鏈）時可能 stack overflow，要改成自己管理 stack。

考研重點：題型地圖

題型常見度解題步驟例題
寫出 BFS / DFS 順序很常考先列每個頂點的相鄰點（照題目規定的順序），BFS 畫 queue、DFS 畫呼叫堆疊，一步一步追例題
程式建圖後的走訪順序常考先依程式畫出真正的相鄰串列（插在前端會反序），再追蹤例題
判斷哪個序列不可能常考DFS：模擬路徑 stack，頂端還有未訪鄰居卻跳走就不合法；BFS：檢查分層與發現順序例題
複雜度：串列 vs 矩陣很常考串列 O(V + E)、矩陣 O(V²)，理由是找相鄰點要掃整列例題
發現 / 完成時間、最短邊數常考DFS 進入 +1、離開 +1；BFS 的 dist = 父節點 + 1例題
生成樹林、連通元件計數偶爾樹邊 = V − k，非樹邊 = E − V + k例題
證明 BFS 求得最短路徑偶爾證明 queue 內 dist 單調、最多差 1，再對 dist 歸納例題

易錯點

  • BFS 從 queue 取出時才標記 visited → 放進 queue 時就要標記，否則同一個頂點會被重複放入 例題
  • 走訪順序只跟圖的形狀有關 → 也取決於相鄰串列的順序；插在前端建立的串列是反序的 例題
  • DFS 拜訪完 v 的一個鄰居，就接著拜訪 v 的下一個鄰居 → 那是 BFS 的做法；DFS 會先從那個鄰居繼續往深處走，走到死路才回到 v 例題
  • 用相鄰矩陣也是 O(V + E) → 矩陣找鄰居要掃整列 n 格，總共 O(V²)，和邊數無關 例題
  • DFS 也能求最短路徑 → DFS 樹的路徑可能繞遠路；無權圖的最短邊數要用 BFS 例題
  • 題目沒規定相鄰點順序時，只要每個點都拜訪一次就是合法的 DFS 順序 → 合法序列可以有很多種，但只要目前頂點還有未拜訪的鄰居，就不能跳去別的分支 例題
