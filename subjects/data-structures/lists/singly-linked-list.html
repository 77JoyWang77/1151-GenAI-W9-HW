Singly Linked List 單向鏈結串列不用搬資料，改幾個指標就能插入和刪除

Ch4 Linked Lists 難度 pointer insert delete reverse

為什麼需要鏈結串列

陣列把元素放在連續的記憶體裡，好處是可以用索引直接算出第 i 個元素的位址，存取是 O(1)。但連續也帶來兩個麻煩：

  • 插入、刪除要搬資料：在一個 1000 個元素的有序陣列最前面插入一個數，後面 1000 個元素都要往後移一格；刪除也一樣要往前補。平均要搬 n / 2 個元素，是 O(n)。
  • 大小要先決定：陣列宣告時就要給大小，給太小會不夠用，給太大又浪費；要擴充只能另外配置一塊更大的空間，把全部資料複製過去。

Linked List（鏈結串列）換一個想法：元素不必放在一起，每個元素旁邊多存一個「下一個元素在哪裡」的指標，用指標把散落各處的元素串成一條。要插入時，只要改一兩個指標讓它「接進來」，其他元素完全不用動；要多少空間就隨時用 malloc 配置一個節點，不用事先決定大小。

代價是失去了隨機存取：想找第 k 個元素，只能從頭沿著指標走 k − 1 步，是 O(k)。所以鏈結串列適合「常常插入、刪除，但很少依位置查詢」的情況，和陣列剛好互補。

節點的結構：data 加上 link

鏈結串列由一個個 Node（節點）組成，每個節點有兩個欄位：data 存資料，link 存下一個節點的位址。最後一個節點後面沒有東西，link 設成 NULL，代表串列到此結束。另外用一個指標 first（也常叫 head）指向第一個節點，整條串列就靠它找到；first 是 NULL 就是空串列。

因為每個節點只知道「下一個」在哪裡、不知道「上一個」，只能單方向往後走，所以叫 Singly Linked List（單向鏈結串列）。之後會學到每個節點也記住前一個的雙向串列，以及最後一個節點接回第一個的環狀串列。

在 C 裡，節點是一個 Self-referential Structure（自我參考結構）：結構裡有一個指向同型別結構的指標。習慣上先用 typedef 定義「指向節點的指標」型別 listPointer，程式會比較好讀。節點要用 malloc 動態配置，配置失敗會回傳 NULL，一定要檢查。

看程式碼：節點結構與 newNode()
節點結構與 newNode()
typedef struct node *listPointer;
typedef struct node {
  int data;
  listPointer link;                            /* 指向下一個節點，最後一個是 NULL */
} node;

listPointer newNode(int x) {
  listPointer p = malloc(sizeof(node));
  if (p == NULL) { printf("Memory Full\n"); exit(1); }
  p->data = x;
  p->link = NULL;
  return p;
}

走訪：沿著 link 一路走到 NULL

所有操作的基礎都是 Traversal（走訪）：用一個指標 p 從 first 出發，處理完目前的節點後執行 p = p->link 移到下一個，直到 p 變成 NULL。印出所有元素、計算長度、搜尋某個值都是這個樣子，差別只在每一步做什麼。

注意走訪時要用另一個指標 p，不能直接移動 first。first 一旦往後移，前面的節點就再也找不到了（沒有任何指標指向它們），不但資料不見，記憶體也沒辦法 free，造成 Memory Leak（記憶體洩漏）。

搜尋時最好情況是第一個就找到，比較 1 次；最差情況是要找的值在最後一個或根本不存在，要比較 n 次，所以是 O(n)。即使串列是排序好的，也不能用二分搜尋：二分搜尋需要直接跳到中間，而鏈結串列要走到中間本身就要 n / 2 步。

看程式碼：printList()、length()、search()
printList()、length()、search()
void printList(listPointer first) {
  for (listPointer p = first; p != NULL; p = p->link)
    printf("%d -> ", p->data);
  printf("NULL\n");
}

int length(listPointer first) {
  int count = 0;
  for (listPointer p = first; p != NULL; p = p->link)
    count++;
  return count;
}

listPointer search(listPointer first, int x) {
  listPointer p = first;
  while (p != NULL && p->data != x)            /* 一個一個往後找 */
    p = p->link;
  return p;                                    /* 找不到時 p 是 NULL */
}

插入：先接後面，再接前面

插入分成兩種情況，關鍵差別在「first 會不會改變」。

插在最前面

新節點 p 要變成第一個：先讓 p->link 指向原本的第一個，再把 first 改成 p。因為 first 本身會被改掉，函式要收 first 的位址（listPointer *first，也就是指標的指標），才能改到呼叫端的那個變數。如果只傳 listPointer first，函式裡改的只是一份複本，回到呼叫端 first 還是指著舊的第一個，新節點就遺失了。

插在某個節點 prev 之後

這種情況 first 不變，只要兩個步驟，順序不能顛倒：

  1. p->link = prev->link;：新節點先指向 prev 原本的下一個（先接後面）。
  2. prev->link = p;：prev 改指向新節點（再接前面）。

如果先做第 2 步，prev->link 已經變成 p，原本的下一個節點就沒有任何指標記得了；接著第 1 步的 p->link = prev->link 讀到的是 p 自己，p 指向自己形成一個小環，後半段整個遺失。記法很簡單：改掉一個指標之前，要先確定它原本指的東西有別人記住。

不管串列多長，插入本身都只改 2 個指標，是 O(1)。但「找到 prev」通常要從頭走，像在一個遞增串列中插入並維持排序（insertSorted），要先找到第一個 ≥ x 的節點，最差走 n 步，所以整體是 O(n)。找的時候要用兩個指標：cur 往前探，prev 跟在後面一格，因為單向串列沒辦法從 cur 往回找到它的前一個。

看程式碼：insertFront()、insertAfter()、insertSorted()
insertFront()、insertAfter()、insertSorted()
void insertFront(listPointer *first, int x) {
  listPointer p = newNode(x);
  p->link = *first;                            /* 新節點先指向原本的第一個 */
  *first = p;                                  /* 再讓 first 指向新節點 */
}

void insertAfter(listPointer prev, int x) {
  listPointer p = newNode(x);
  p->link = prev->link;                        /* 先接後面 */
  prev->link = p;                              /* 再接前面 */
}

void insertSorted(listPointer *first, int x) {
  listPointer prev = NULL, cur = *first;
  while (cur != NULL && cur->data < x) {       /* 找第一個 >= x 的節點 */
    prev = cur;
    cur = cur->link;
  }
  if (prev == NULL) insertFront(first, x);     /* 插在最前面要改 first */
  else insertAfter(prev, x);
}

刪除：一定要找到前一個節點

刪掉節點 cur，就是讓它的前一個節點直接跳過它：prev->link = cur->link，然後 free(cur) 把記憶體還回去。所以刪除的重點不是 cur，而是 cur 的前一個。做法和 insertSorted 一樣，搜尋時讓 prev 跟在 cur 後面一格。

要分三種情況檢查：

情況怎麼判斷要做什麼
找不到cur 走到 NULL什麼都不改，回傳失敗
刪第一個prev 還是 NULL*first = cur->link：first 往後移，所以函式同樣要收 listPointer *first
刪中間或最後prev 不是 NULLprev->link = cur->link；刪最後一個時 cur->link 是 NULL，prev 就變成新的最後一個

為什麼不能「只給 cur 就刪掉 cur」？因為改的是 prev 的 link，而單向串列從 cur 找不到 prev，只能從頭再走一次，O(n)。有一個常見的取巧：把 cur 下一個節點的資料複製到 cur，再刪掉下一個節點，這樣只要 O(1)；但如果 cur 是最後一個節點就沒有「下一個」可以抄，這招不能用，考題常拿這點問。

最後別忘了 free。free(cur) 之後 cur 就不能再使用（變成 dangling pointer），所以 cur->link 一定要在 free 之前讀出來。

看程式碼：deleteValue()
deleteValue()
int deleteValue(listPointer *first, int x) {
  listPointer prev = NULL, cur = *first;
  while (cur != NULL && cur->data != x) {      /* 找要刪的節點，順便記住前一個 */
    prev = cur;
    cur = cur->link;
  }
  if (cur == NULL) return 0;                   /* 找不到 */
  if (prev == NULL) *first = cur->link;        /* 刪第一個：first 往後移 */
  else prev->link = cur->link;                 /* 前一個直接跳過 cur */
  free(cur);
  return 1;
}

動手操作

下面的串列是遞增排序的。輸入一個數字按 insertSorted，可以看到 prev 和 cur 一起往後找位置，再依序改兩個 link；按 insertFront 會直接插在最前面（不維持排序）；delete 和 search 輸入要找的值；reverse 不用輸入，會把整條串列反轉。橘色的箭頭是這一步剛被改掉的 link。

反轉串列：三個指標

反轉是考研最愛考的鏈結串列題，要求通常是「不配置新節點、O(1) 額外空間」。想法是從頭到尾把每一個 link 的方向反過來。用三個指標：

  • prev：已經反轉好的部分的第一個節點，一開始是 NULL。
  • cur：現在要處理的節點，一開始是 first。
  • next：cur 原本的下一個。改掉 cur->link 之前要先把它存起來，否則後面的節點全部找不到。

每一輪做四件事：記住 next、把 cur->link 改成 prev、prev 移到 cur、cur 移到 next。cur 變成 NULL 時，prev 停在原本的最後一個節點，也就是反轉後的第一個，回傳它。

例子：反轉 1 → 2 → 3 → NULL

輪next做完後已反轉的部分（從 prev 開始）還沒處理的部分（從 cur 開始）
開始—NULL1 → 2 → 3 → NULL
121 → NULL2 → 3 → NULL
232 → 1 → NULL3 → NULL
3NULL3 → 2 → 1 → NULLNULL，迴圈結束

每個節點只被處理一次，n 個節點迴圈跑 n 輪，時間 O(n)；只多用了三個指標，額外空間 O(1)。注意函式是回傳新的第一個節點，呼叫端要寫 first = reverse(first);。如果只呼叫 reverse(first) 而沒有接回傳值，first 還指著原本的第一個節點，而它現在是最後一個，從 first 印出來只剩一個元素。

也可以用遞迴：先反轉第一個節點之後的部分，再把第一個節點接到尾巴。寫起來短，但遞迴深度是 n，要 O(n) 的 stack 空間，串列很長時可能 stack overflow，所以題目要求 O(1) 空間時要用迴圈版。

看程式碼：reverse()
reverse()
listPointer reverse(listPointer first) {
  listPointer prev = NULL, cur = first, next;
  while (cur != NULL) {
    next = cur->link;                          /* 先記住下一個，不然會斷掉 */
    cur->link = prev;                          /* 箭頭反過來指向前一個 */
    prev = cur;                                /* 三個指標一起往後移 */
    cur = next;
  }
  return prev;                                 /* prev 停在原本的最後一個 */
}

Dummy Head：讓第一個節點不再特別

回頭看 insertSorted 和 deleteValue，都有一個「prev 是 NULL」的特殊情況，因為第一個節點前面沒有節點，只能改 first。這種邊界情況是寫錯最多的地方。

解法是在最前面放一個不存資料的 Dummy Head（虛擬頭節點，也叫 header node）。這樣每個資料節點前面都一定有一個節點，插入和刪除都能用同一套「改 prev->link」的寫法，函式也不用再收指標的指標，因為 head 本身永遠不會變。代價只是多一個節點的空間。

比較 insertSortedDummy 和前面的 insertSorted：prev 直接從 head 出發，迴圈改成看 prev->link，最後一律呼叫 insertAfter，少了一個 if。考題看到 header node，判斷空串列、計算長度時要記得 dummy 不算在內。

看程式碼：insertSortedDummy()
insertSortedDummy()
void insertSortedDummy(listPointer head, int x) {
  listPointer prev = head;                     /* head 是不存資料的 dummy */
  while (prev->link != NULL && prev->link->data < x)
    prev = prev->link;
  insertAfter(prev, x);                        /* 不需要特別處理最前面 */
}

其他常考操作

  • 找中間節點：用快慢兩個指標，slow 一次走一步、fast 一次走兩步，fast 走到底時 slow 剛好在中間。只走一遍就好，不用先算長度。n 是偶數時，下面的寫法停在後半的第一個（1 2 3 4 停在 3）。
  • 串接兩條串列：走到第一條的最後一個節點，把它的 link 指向第二條的開頭。要走完第一條，O(n)；如果平常就多記一個指向最後一個節點的 last 指標，就變成 O(1)。
  • 釋放整條串列：一個一個 free，free 之前要先把 link 存起來，理由和反轉時先存 next 一樣。
  • 找倒數第 k 個：先讓 fast 走 k 步，再讓 slow 和 fast 一起走，fast 到 NULL 時 slow 就是倒數第 k 個，同樣只走一遍。
看程式碼：middle()、concatenate()、freeList()
middle()、concatenate()、freeList()
listPointer middle(listPointer first) {
  listPointer slow = first, fast = first;
  while (fast != NULL && fast->link != NULL) { /* fast 一次走兩步 */
    slow = slow->link;
    fast = fast->link->link;
  }
  return slow;                                 /* 偶數個時回傳後半的第一個 */
}

listPointer concatenate(listPointer a, listPointer b) {
  if (a == NULL) return b;
  listPointer p = a;
  while (p->link != NULL) p = p->link;         /* 走到 a 的最後一個 */
  p->link = b;
  return a;
}

void freeList(listPointer first) {
  while (first != NULL) {
    listPointer next = first->link;            /* free 之前先記住下一個 */
    free(first);
    first = next;
  }
}

陣列與鏈結串列比較

比較項目陣列單向鏈結串列
存取第 k 個O(1)，用索引算位址O(k)，從頭走
已知位置後插入／刪除O(n)，要搬資料O(1)，改指標（刪除要知道前一個）
在最前面插入O(n)O(1)
排序後搜尋O(log n)，二分搜尋O(n)，不能二分
大小宣告時固定隨時 malloc，可以一直長
額外空間沒有每個節點多一個指標
快取效率好，資料連續較差，節點散在各處

應用上，鏈結串列常用來實作 stack 和 queue（不用擔心滿）、多項式（只存非零項）、圖的 adjacency list，以及雜湊表處理碰撞的 chaining。只要資料量會變、而且主要操作是在頭尾或已知位置插入刪除，就適合用鏈結串列。

考研重點：題型地圖

題型常見度解題步驟例題
指標操作追蹤很常考每一行都畫出「誰指向誰」，被改掉的箭頭馬上擦掉重畫例題
插入／刪除的敘述填空很常考插入先接後面再接前面；刪除改前一個節點的 link，最後 free例題
反轉串列很常考prev、cur、next 三個指標，先存 next 再改 link；記得接回傳值例題
各操作的時間複雜度常考看「要不要從頭走」：需要前一個節點或第 k 個就是 O(n)例題
遞迴函式的輸出常考畫出呼叫樹，遞迴呼叫前後的 printf 分開記例題
寫函式：快慢指標、合併常考倒數第 k 個、找中間用兩個速度不同的指標；合併用 dummy 節點接尾巴例題

易錯點

  • 插入時先寫 prev->link = p → 要先 p->link = prev->link，否則後半段遺失 例題
  • 鏈結串列也能 O(1) 取第 k 個、排序後能二分搜尋 → 沒有隨機存取，走到第 k 個要 O(k) 例題
  • 有 last 指標，刪除最後一個就是 O(1) → 要改的是倒數第二個的 link，還是得從頭找 例題
  • 呼叫 reverse(first) 之後 first 就是新的開頭 → 要寫 first = reverse(first)；沒接回傳值時 first 指著原本的頭，現在是尾巴 例題
  • 刪除後再讀 cur->link 往下走 → free 之後不能再用 cur，要先把 cur->link 存起來或先接好 例題
