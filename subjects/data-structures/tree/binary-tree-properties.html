什麼是二元樹

一般的 Tree（樹）每個節點可以有任意多個子節點，寫程式時不知道要預留幾個指標。Binary Tree（二元樹）把子節點限制成最多兩個，而且分成左、右，每個節點固定只需要兩個指標，結構規則、好處理；後面的 BST、heap、運算式樹都是二元樹。

精確的定義是遞迴的：二元樹是一個有限的節點集合，它可以是空的；不是空的話，由一個根，加上兩棵互不相交的二元樹（左子樹、右子樹）組成。這個定義和一般的樹有兩個差別，選擇題很愛考：

  • 二元樹可以是空的，一般的樹至少要有一個節點（根）。
  • 二元樹的左右是有區別的：根只有一個子節點時，它是左子還是右子會被當成兩棵不同的二元樹；在一般的樹裡，這兩種是同一棵。

常用術語：一個節點的子節點個數叫 Degree（分支度），二元樹每個節點的分支度只會是 0、1、2；分支度 0 的節點是 Leaf（葉子），其他的是內部節點。根在第 1 層，往下每層加 1；最大的層數就是樹的 Height（高度，也叫 depth）。本頁一律用「根在第 1 層、只有根時高度是 1」，有些題目從 0 開始算，公式要跟著減 1，作答前一定要先看清楚。

三個基本性質

性質 1：第 i 層最多 2i−1 個節點

第 1 層只有根，1 個；每個節點最多兩個子節點，所以下一層最多是上一層的兩倍：1、2、4、8……，第 i 層最多 2i−1 個。

性質 2：高度 k 的二元樹最多 2k − 1 個節點

把每一層的最大值加起來：1 + 2 + 4 + … + 2k−1 = 2k − 1。反過來說，n 個節點的二元樹，高度至少是 ⌈log₂(n + 1)⌉；最多則是 n（每層只有一個節點，排成一條鏈）。例如 n = 100，高度介於 ⌈log₂101⌉ = 7 和 100 之間。BST 的效能就取決於高度落在這個範圍的哪一端。

第 i 層最多 2^(i−1) 個　　高度 k 最多 2^k − 1 個　　n 個節點的高度 ≥ ⌈log₂(n + 1)⌉

性質 3：葉子數 n0 = n2 + 1

這是二元樹最重要、最常考的公式。設分支度 0、1、2 的節點各有 n0、n1、n2 個，則不管樹長什麼樣子，一定有 n0 = n2 + 1。證明只要從兩個角度數同一件事：

  1. 數節點：n = n0 + n1 + n2。
  2. 數邊：除了根以外，每個節點都有一條邊連到父節點，所以邊數 = n − 1。換一個角度，每條邊都是從某個父節點往下長出來的，分支度 1 的節點長出 1 條、分支度 2 的長出 2 條，所以邊數 = n1 + 2·n2。
  3. 兩式相等：n0 + n1 + n2 − 1 = n1 + 2·n2，消掉 n1 就得到 n0 = n2 + 1。

以圖 1 驗證：分支度 2 的有 A、B、E 三個，葉子有 D、F、G、H 四個，4 = 3 + 1。注意 n1 不影響結果：分支度 1 的節點不管有幾個，都不會改變葉子和分支度 2 節點的差。

同樣的「數邊」方法可以推廣到任何樹：分支度 d 的節點有 nd 個，邊數 n − 1 = Σ d·nd，整理後得到 n0 = 1 + Σ (d − 1)·nd。例如每個節點分支度都是 0 或 3 的樹，n0 = 2·n3 + 1。

特殊的二元樹：歪斜、完滿、完全

  • Skewed Binary Tree（歪斜二元樹）：每個節點只有左子（左歪斜）或只有右子（右歪斜），n 個節點高度就是 n，等於一條鏈結串列。這是 BST 退化的最差情況。
  • Full Binary Tree（完滿二元樹）：高度 k、而且剛好有 2k − 1 個節點，也就是每一層都填滿。
  • Complete Binary Tree（完全二元樹）：n 個節點、高度 k，而且這 n 個節點剛好對應到「高度 k 的完滿二元樹」中編號 1～n 的位置。直覺上就是除了最後一層之外都填滿，最後一層的節點全部靠左，中間不能有空洞。完滿二元樹一定是完全二元樹，反過來不一定。

完全二元樹的形狀只由 n 決定，所以可以直接算出很多數字：高度是 ⌊log₂n⌋ + 1；節點 i 是葉子若且唯若 2i > n，所以葉子有 n − ⌊n / 2⌋ = ⌈n / 2⌉ 個；n 是偶數時恰好有 1 個節點分支度是 1（編號 n / 2，它只有左子），n 是奇數時沒有。例如 n = 100：高度 7、葉子 50 個、n1 = 1、n2 = 49，再用 n0 = n2 + 1 驗算，50 = 49 + 1。

名詞要小心：「Full Binary Tree」在不同的書有兩種意思，一種是上面「每一層都填滿」的完滿，另一種是「每個節點都是 0 個或 2 個子節點」（也叫 strict 或 proper binary tree，圖 2(c) 的 C 只有一個子節點就不符合）。考題用的是中文「完滿」時通常是前者；看到英文 full 而題意不清楚時，寫出你採用的定義再作答。

n 個節點有幾種不同的二元樹

把 n 個節點的二元樹想成：根拿掉 1 個，剩下 n − 1 個分給左右子樹，左邊 i 個、右邊 n − 1 − i 個。設 bn 是 n 個節點的二元樹形狀數，b0 = 1（空樹一種），則 bn = Σ bi·bn−1−i。這個數列就是 Catalan Number（卡特蘭數），有封閉式：

b(n) = C(2n, n) / (n + 1) = (2n)! / (n! · (n + 1)!)　　b(1..6) = 1, 2, 5, 14, 42, 132

例如 3 個節點有 b3 = 5 種（圖 3），其中 4 種高度 3、只有 1 種高度 2。高度剛好是 n 的形狀，每往下一層都可以選左或右，共 2n−1 種：n = 4 時 14 種裡有 8 種高度 4。同一個 Catalan 數也出現在「n 個元素依序 push 進 stack，可能的 pop 順序有幾種」，以及「給定前序走訪，對應幾種二元樹」，考題常常把它們串在一起。

看程式碼：countShapes()：算出 b(n)
countShapes()：算出 b(n)
long long countShapes(int n) {
  long long b[40] = {1};                       /* b[0] = 1：空樹只有一種 */
  for (int k = 1; k <= n; k++) {
    b[k] = 0;
    for (int i = 0; i < k; i++)                /* 左子樹 i 個、右子樹 k - 1 - i 個 */
      b[k] += b[i] * b[k - 1 - i];
  }
  return b[n];
}

陣列表示法：照編號放

想像這棵樹是某棵完滿二元樹的一部分，把位置由上到下、由左到右編號 1、2、3……，編號 i 的節點就放在 a[i]。這樣不需要任何指標，父子關係直接用編號算出來（a[0] 不用）：

父節點 = ⌊i / 2⌋（i ≠ 1）　　左子 = 2i（若 2i ≤ n）　　右子 = 2i + 1（若 2i + 1 ≤ n）

為什麼是 2i？第 d 層第一個位置的編號是 2d−1，同一層往右數第 j 個是 2d−1 + j；它的左子在下一層的第 2j 個，編號 2d + 2j = 2(2d−1 + j)，剛好是 2 倍。如果陣列從 0 開始放根，公式變成父節點 (i − 1) / 2、左子 2i + 1、右子 2i + 2。

陣列表示法對完全二元樹最划算：n 個節點剛好用 a[1..n]，一格都不浪費，這也是 heap 用陣列存的原因。但對一般的二元樹，空位也要佔著一格，否則後面的編號會錯位。最差的是歪斜樹：高度 k 只有 k 個節點，卻要用到編號 2k − 1 的位置，k = 20 時只有 20 個節點卻要配置 1,048,575 格。另外插入、刪除節點時，整棵子樹的編號都會跟著變，要搬動很多元素。

看程式碼：buildFromArray()：陣列轉成鏈結
buildFromArray()：陣列轉成鏈結
treePointer buildFromArray(const char a[], int size, int i) {
  if (i > size || a[i] == '-') return NULL;    /* 超出陣列或空位：空樹 */
  treePointer t = newNode(a[i]);
  t->left = buildFromArray(a, size, 2 * i);    /* 左子在 2i */
  t->right = buildFromArray(a, size, 2 * i + 1); /* 右子在 2i + 1 */
  return t;
}

鏈結表示法：每個節點兩個指標

一般的二元樹多半用鏈結表示：每個節點有 left、data、right 三個欄位，left、right 分別指向左、右子樹的根，沒有子節點就是 NULL。用多少節點就配置多少，歪斜樹也不浪費；插入、刪除只要改指標。缺點是找不到父節點（需要的話要再多加一個 parent 欄位），而且每個節點都多花兩個指標的空間。

這裡有一個常考的數字：n 個節點的鏈結二元樹，共有 2n 個指標欄位，其中只有 n − 1 個真的指向節點（每個非根節點被它的父節點指一次），剩下 n + 1 個是 NULL。超過一半的指標是空的，引線二元樹就是把這些 NULL 拿來存走訪時的前後節點。

看程式碼：節點結構與 newNode()
節點結構與 newNode()
typedef struct treeNode *treePointer;
typedef struct treeNode {
  treePointer left;                            /* 左子樹 */
  char data;
  treePointer right;                           /* 右子樹 */
} treeNode;

treePointer newNode(char c) {
  treePointer p = malloc(sizeof(treeNode));
  if (p == NULL) { printf("Memory Full\n"); exit(1); }
  p->data = c;
  p->left = p->right = NULL;
  return p;
}

樹的性質幾乎都能用同一個遞迴套路算出來：空樹回傳基本值，否則把左右子樹的結果合起來。節點數 = 1 + 左 + 右；高度 = 1 + max(左, 右)；分支度計數則是在每個節點看它有幾個非 NULL 的子節點。每個節點只拜訪一次，都是 O(n)。

看程式碼：countNodes()、height()、countDegree()
countNodes()、height()、countDegree()
int countNodes(treePointer t) {
  if (t == NULL) return 0;
  return 1 + countNodes(t->left) + countNodes(t->right);
}

int height(treePointer t) {                    /* 只有根時高度是 1，空樹是 0 */
  if (t == NULL) return 0;
  int hl = height(t->left), hr = height(t->right);
  return 1 + (hl > hr ? hl : hr);
}

void countDegree(treePointer t, int cnt[3]) {  /* cnt[d]：分支度為 d 的節點數 */
  if (t == NULL) return;
  int d = (t->left != NULL) + (t->right != NULL);
  cnt[d]++;
  countDegree(t->left, cnt);
  countDegree(t->right, cnt);
}

判斷完全二元樹時，可以利用陣列表示法的編號：先算出 n，再從根開始幫每個節點標上它在陣列中的編號（左子 2i、右子 2i + 1），只要有任何節點的編號超過 n，就代表編號 1～n 之間有空洞，不是完全二元樹。判斷「每個節點都是 0 或 2 個子節點」則是檢查有沒有節點剛好只有一邊是 NULL。

看程式碼：isComplete()、isStrict()
isComplete()、isStrict()
int isComplete(treePointer t, int i, int n) {
  if (t == NULL) return 1;
  if (i > n) return 0;                         /* 編號超過 n 代表中間有空洞 */
  return isComplete(t->left, 2 * i, n) && isComplete(t->right, 2 * i + 1, n);
}

int isStrict(treePointer t) {
  if (t == NULL) return 1;
  if ((t->left == NULL) != (t->right == NULL)) return 0; /* 只有一個子節點 */
  return isStrict(t->left) && isStrict(t->right);
}

易錯點

  • 高度 k 最多 2k 個節點 → 是 2k − 1（根在第 1 層）；若題目讓根在第 0 層，要改成 2k+1 − 1 例題
  • 要知道 n1 才能算葉子數 → n0 = n2 + 1 和 n1 無關 例題
  • 最後一層有空位就不是完全二元樹 → 最後一層可以不滿，只要節點全部靠左、編號 1～n 沒有空洞 例題
  • 只有左子和只有右子是同一棵二元樹 → 二元樹分左右，這是兩棵不同的樹；3 個節點有 5 種而不是 2 種 例題
  • n 個節點的鏈結二元樹有 n 個 NULL 指標 → 2n 個指標中有 n − 1 個指向節點，NULL 是 n + 1 個 例題
