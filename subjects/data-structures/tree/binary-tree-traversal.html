Binary Tree Traversal 二元樹走訪與重建前序、中序、後序只差在什麼時候拜訪自己

Ch5 Trees 難度 preorder inorder postorder level-order

什麼是走訪

陣列和鏈結串列都是「一條線」，要把每個元素看過一遍，只有從頭走到尾這一種自然的順序。樹就不一樣了：每個節點可能分出兩條路，先走左邊還是右邊、什麼時候處理自己，都會得到不同的順序。Traversal（走訪）就是用一套固定的規則，把樹中每個節點剛好拜訪一次。

「拜訪」可以是任何動作：印出資料、加總、複製、釋放記憶體、計算運算式的值。很多樹的演算法本質上都是「挑一種走訪順序，在拜訪時做點事情」，所以走訪是學習樹的第一個基本功。

對一個節點來說，要做的事只有三件：拜訪自己（記作 V）、走訪左子樹（L）、走訪右子樹（R）。慣例上一律先左後右，於是依照 V 放在哪個位置，得到三種Depth-First Traversal（深度優先走訪）：

  • Preorder（前序）：V L R，先拜訪自己，再走左、右子樹。
  • Inorder（中序）：L V R，左子樹全部走完才拜訪自己，最後走右子樹。
  • Postorder（後序）：L R V，兩棵子樹都走完，最後才拜訪自己。

另外還有一種完全不同的思路：Level-order Traversal（層序走訪），從根開始一層一層、每層由左到右拜訪，屬於Breadth-First（廣度優先）。

「前、中、後」說的是根（V）在什麼時候被拜訪：在左右子樹之前、之間、之後。左子樹永遠在右子樹之前。

遞迴寫法：三種走訪只差一行的位置

樹是遞迴定義的：一棵樹 = 根 + 左子樹 + 右子樹，而左、右子樹本身也是樹。所以走訪最自然的寫法就是遞迴：遇到 NULL（空樹）直接返回，否則照 V、L、R 的順序做三件事。三個函式的程式碼幾乎一模一樣，只有 printf 那一行的位置不同。

看程式碼：前序／中序／後序（遞迴）
preorder()：V L R
void preorder(Node *t) {
  if (t == NULL) return;
  printf("%c ", t->data);                        /* V：先拜訪自己 */
  preorder(t->left);                             /* L */
  preorder(t->right);                            /* R */
}
inorder()：L V R
void inorder(Node *t) {
  if (t == NULL) return;
  inorder(t->left);                              /* L */
  printf("%c ", t->data);                        /* V：左子樹走完才拜訪自己 */
  inorder(t->right);                             /* R */
}
postorder()：L R V
void postorder(Node *t) {
  if (t == NULL) return;
  postorder(t->left);                            /* L */
  postorder(t->right);                           /* R */
  printf("%c ", t->data);                        /* V：兩棵子樹都走完才拜訪自己 */
}

追一次前序

以圖 1 的樹為例，preorder(A) 一進來就輸出 A，接著呼叫 preorder(B)。B 也先輸出自己，再往左進入 D；D 沒有子節點，兩次遞迴都碰到 NULL 立刻返回，回到 B，改走 B 的右子樹 E……整個過程可以整理成下表：

呼叫做的事目前輸出
preorder(A)輸出 A，進入左子樹 BA
preorder(B)輸出 B，進入左子樹 DA B
preorder(D)輸出 D，左右都是 NULL，返回 BA B D
preorder(E)輸出 E，進入左子樹 GA B D E
preorder(G)輸出 G，返回 E → B → A，A 改走右子樹 CA B D E G
preorder(C)輸出 C，左是 NULL，進入右子樹 FA B D E G C
preorder(F)、(H)、(I)輸出 F，再依序輸出左子 H、右子 IA B D E G C F H I

每個節點都被呼叫一次，NULL 的呼叫有 n + 1 次（n 個節點的二元樹有 n + 1 個空指標），每次呼叫只做常數的工作，所以三種走訪都是 O(n) 時間。遞迴最深會到樹高 h，額外空間是 O(h)：平衡時約 log n，退化成一條鏈時是 n。

手算技巧：沿著外圍繞一圈

考試時不必一層一層展開遞迴。想像從根的左邊出發，貼著樹的外圍逆時針繞一圈（往下走時靠左、往上回來時靠右），每個節點會被經過三次：第一次是從它的左側經過，第二次是從它的下方經過（左子樹走完、要轉向右子樹的時候），第三次是從它的右側離開。

依照這個方法，只要決定在哪個記號「寫下」節點，三種走訪一次就能寫出來。寫完可以用下面三個性質快速檢查：

  • 前序的第一個一定是根，後序的最後一個一定是根。
  • 中序裡，根的左邊全部是左子樹、右邊全部是右子樹。
  • 葉節點在三種走訪中的相對順序都一樣（範例中葉節點 D、G、H、I 在三種走訪裡都是這個順序），因為葉節點沒有子樹，V 放在哪裡都不會改變它們之間的先後。

不用遞迴：用 stack 做中序

遞迴之所以能「走完左子樹再回來處理自己」，是因為系統的 call stack 幫我們記住了回來的位置。如果不能用遞迴（例如考題要求、或樹太深怕 stack overflow），就自己準備一個 Stack 來記：

  1. 從目前節點開始一路往左走，沿途把經過的節點 push 進 stack。這些節點都還不能輸出，因為它們的左子樹還沒處理。
  2. 走到 NULL 時，pop 出 stack 頂端的節點。它的左子樹已經處理完了，所以現在輸出它。
  3. 接著把目標轉到它的右子樹，回到第 1 步。
  4. 當目前節點是 NULL 而且 stack 也空了，就全部走完。

stack 裡永遠只放「從根到目前位置這條路徑上，還沒輸出的祖先」，所以最多同時放 h 個節點，額外空間和遞迴版一樣是 O(h)。以範例樹來說，stack 最多同時有 3 個節點（A、B、D 或 A、E、G 這類）。

看程式碼：inorderIter()：用 stack 的中序
inorderIter()：用 stack 的中序
void inorderIter(Node *t) {
  Node *stack[100];
  int top = -1;
  while (t != NULL || top != -1) {
    while (t != NULL) {                          /* 一路往左走，沿途 push */
      stack[++top] = t;
      t = t->left;
    }
    t = stack[top--];                            /* 左邊到底了，pop 出來拜訪 */
    printf("%c ", t->data);
    t = t->right;                                /* 再處理它的右子樹 */
  }
}

層序走訪：用 queue 一層一層來

層序走訪要「先把同一層全部拜訪完，再往下一層」。拜訪 B 的時候，B 的子節點 D、E 必須等到同一層的 C 拜訪完才輪到，這種「先發現的先處理」正好是 Queue 的 FIFO 特性：

  1. 把根放進 queue。
  2. 只要 queue 不空：從前端取出一個節點拜訪，再把它的左、右子節點（不是 NULL 的）依序放到 queue 尾端。

因為每一層的節點都比下一層的節點早進 queue，所以輸出順序一定是一層一層的。時間仍是 O(n)；queue 裡同時最多放「最寬那一層」的節點數，完全二元樹的最後一層約有 n / 2 個節點，所以最差空間是 O(n)。

看程式碼：levelorder()：用 queue 的層序走訪
levelorder()：用 queue 的層序走訪
void levelorder(Node *t) {
  Node *queue[100];
  int front = 0, rear = 0;                       /* front：下一個要取的；rear：下一個空位 */
  if (t == NULL) return;
  queue[rear++] = t;
  while (front < rear) {
    Node *p = queue[front++];
    printf("%c ", p->data);
    if (p->left)  queue[rear++] = p->left;       /* 先左後右放進 queue */
    if (p->right) queue[rear++] = p->right;
  }
}

深度優先（前、中、後序）靠的是 stack（遞迴就是隱形的 stack）；廣度優先（層序）靠的是 queue。這個對應之後在圖的 DFS、BFS 會再出現一次。

動手操作

在輸入框用層序輸入一棵樹：第 i 格（從 0 開始）的左子節點在第 2i + 1 格、右子節點在第 2i + 2 格，空的位置寫 #。例如預設的 A B C D E # F # # G # # # H I 就是圖 1 的樹。選擇一種走訪後按播放，可以看到目前所在的節點、已輸出的結果，以及 stack 或 queue 裡的內容；按「運算式樹」可以載入下一節的例子。

由走訪結果重建二元樹

反過來問：給你走訪結果，能不能畫出原本的樹？只給一種走訪通常不行，例如前序 A B 可能是「B 是 A 的左子」也可能是「右子」。但只要有中序、再搭配前序、後序或層序其中一種，就能唯一決定這棵樹：

  • 前序的第一個（或後序的最後一個、層序的第一個）告訴我們誰是根。
  • 在中序裡找到根，左邊就是左子樹的所有節點、右邊就是右子樹，也就知道兩邊各有幾個節點。
  • 對左、右兩邊分別重複同樣的步驟，直到每一段只剩 0 或 1 個節點。

例子：前序 A B D G C E H F，中序 D G B A E H C F

處理的範圍根（前序第一個）中序切開結論
前序 A B D G C E H FAD G B ｜ A ｜ E H C F左子樹 3 個、右子樹 4 個
左：前序 B D GBD G ｜ B ｜ （空）B 只有左子樹 {D, G}
前序 D GD（空）｜ D ｜ GG 是 D 的右子
右：前序 C E H FCE H ｜ C ｜ FC 的左子樹 {E, H}、右子 F
前序 E HE（空）｜ E ｜ HH 是 E 的右子

重建完再做一次後序，得到 G D B H E F C A。考試常考「給前序和中序，求後序」，就是這個流程。

前序 + 後序為什麼不行？它們都只能告訴我們誰是根，卻沒辦法切出左右子樹的分界。當某個節點只有一個子節點時，這個子節點放左邊或右邊，前序和後序都完全相同，所以無法區分。每多一個「只有一個子節點」的節點，可能的樹就多一倍。只有在每個節點都是 0 或 2 個子節點（full binary tree）時，前序 + 後序才能唯一決定。

看程式碼：build()：由前序與中序重建
build()：由前序與中序重建
Node *build(const char *pre, const char *in, int n) {
  if (n == 0) return NULL;
  Node *t = newNode(pre[0]);                     /* preorder 的第一個一定是根 */
  int k = 0;
  while (in[k] != pre[0]) k++;                   /* 根在 inorder 的位置：左邊 k 個是左子樹 */
  t->left  = build(pre + 1, in, k);
  t->right = build(pre + 1 + k, in + k + 1, n - k - 1);
  return t;
}

應用：運算式樹

把算式畫成樹：葉節點是運算元、內部節點是運算子，運算子的左右子樹就是它的兩個運算元，這叫Expression Tree（運算式樹）。越晚算的運算子越靠近根，例如 a + b * c − d / e 最後做的是減法，所以根是 −。

這說明了 Stack 那一頁提到的前序式、後序式從哪裡來：它們就是運算式樹的前序與後序走訪。中序走訪會得到我們平常寫的中序式，但會遺失括號：(a + b) * c 和 a + b * c 的樹不同，中序卻都是 a + b * c，所以要輸出正確的中序式時，必須在每棵子樹外加上括號。

用後序走訪還可以直接計算運算式：先算出左、右子樹的值，再套用根的運算子，這正好是 L R V 的順序。同樣的「先處理子樹、再處理自己」也用在計算樹高、計算節點數、釋放整棵樹（一定要先釋放子節點，才能釋放自己）。

走訪順序輔助結構時間額外空間典型用途

考研重點：題型地圖

題型常見度解題步驟例題
寫出走訪結果很常考沿外圍繞一圈，左側記號是前序、下方是中序、右側是後序；寫完檢查根的位置例題
由兩種走訪重建很常考前序（或後序）找根，中序切左右，遞迴處理；最後再做要求的走訪例題
哪些組合能唯一決定常考一定要有中序；前序 + 後序只在 full binary tree 時唯一例題
計數：符合條件的樹有幾棵常考找出「只有一個子節點」的節點數 k，答案是 2ᵏ例題
非遞迴走訪與空間偶爾追蹤 stack 內容；stack 大小 ≤ 樹高，queue 大小 ≤ 最寬一層例題
證明偶爾對節點數做數學歸納：根由前序決定，中序切出的左右子樹大小唯一例題

易錯點

  • 中序就是「由上而下、由左而右」 → 那是層序。中序是左子樹全部走完才輪到根，根會出現在中間 例題
  • 給前序和後序就能畫出唯一的樹 → 只有一個子節點時左右分不出來，一定要有中序（除非是 full binary tree） 例題
  • 重建時把中序切開後，前序也從同一個位置切 → 前序要依「左子樹有幾個節點」來切：根之後的 k 個是左子樹，不是看字母位置 例題
  • 非遞迴中序的 stack 要放得下 n 個節點 → stack 只放路徑上還沒輸出的祖先，最多 h 個 例題
  • 前序 ABC、後序 CBA 只對應一棵樹 → A、B 都只有一個子節點，每個都有左、右兩種可能，共 2 × 2 = 4 棵 例題
