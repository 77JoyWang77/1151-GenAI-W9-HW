Longest Common Subsequence 最長共同子序列比最後一個字元，把問題切成三個更小的問題

Ch5 Dynamic Programming 難度 dynamic programming LCS traceback memoization

問題：兩個字串最長的共同部分

給兩個字串 X 和 Y，想知道它們「最像」到什麼程度。比對兩份檔案哪幾行改過（diff）、比對兩段 DNA 的相似度、抄襲偵測，都會遇到這個問題。最常用的衡量方式是找它們的 Longest Common Subsequence（最長共同子序列，LCS）。

先把「子序列」講清楚：Subsequence（子序列）是從字串中刪掉零個或多個字元、剩下的字元保持原本順序得到的字串。它可以跳著選，但不能調換順序。例如 STONE 的子序列有 SON、TNE、ONE；但 NOE 不是，因為 N 在 O 後面。要特別和 Substring（子字串）分清楚：子字串必須是連續的一段，STONE 的子字串有 TON、ONE，但 SON 不是。

共同子序列是同時是 X 和 Y 子序列的字串，LCS 就是其中最長的一個。注意 LCS 不一定唯一：ABAB 和 BABA 的 LCS 長度是 3，ABA 和 BAB 都是。題目問「LCS 長度」只有一個答案，問「一個 LCS」可能有好幾個正確答案。

暴力法為什麼不行

最直接的方法是列出 X 的所有子序列，逐一檢查它是不是 Y 的子序列，留下最長的。長度 m 的字串，每個字元選或不選，共有 2m 個子序列；每個要花 O(n) 檢查，總共 O(n · 2m)。m = 30 時 230 已經超過 10 億，m = 100 就算到宇宙毀滅也算不完。我們需要利用問題本身的結構。

最佳子結構：只看最後一個字元

記 Xi 是 X 的前 i 個字元（例如 X = STONE 時 X3 = STO），X0 是空字串。關鍵觀察是：只要比較兩個字串的最後一個字元，就能把問題化成更小的同類問題。設 X 長度 m、Y 長度 n，Z = z1…zk 是 X 和 Y 的某一個 LCS：

  1. 如果 xm = yn：那麼 zk = xm = yn，而且 Zk−1 是 Xm−1 和 Yn−1 的 LCS。也就是說，兩邊相同的最後一個字元一定可以放進 LCS 的最後面。
  2. 如果 xm ≠ yn 且 zk ≠ xm：xm 沒用到，Z 是 Xm−1 和 Y 的 LCS。
  3. 如果 xm ≠ yn 且 zk ≠ yn：yn 沒用到，Z 是 X 和 Yn−1 的 LCS。

情況 1 為什麼成立？如果 zk 不是 xm，那把 xm 接在 Z 後面，會得到一個長度 k + 1 的共同子序列，和「Z 最長」矛盾。所以 zk 一定是那個相同的字元；而剩下的 Zk−1 如果不是 Xm−1、Yn−1 的 LCS，就能換成更長的那個再接上 xm，又得到比 Z 更長的答案，同樣矛盾。這種「用更好的子問題解替換，會讓整體更好」的論證叫 Cut-and-Paste（剪貼論證），是證明 Optimal Substructure（最佳子結構）的標準手法。

情況 2、3 的意思是：最後兩個字元不同時，它們不可能同時出現在 LCS 的最後，至少要丟掉一個。我們不知道丟哪個比較好，所以兩種都試，取比較大的。

令 c[i][j] 為 Xi 和 Yj 的 LCS 長度，就得到遞迴式：

         ┌ 0                              若 i = 0 或 j = 0
c[i][j] = ┤ c[i−1][j−1] + 1                若 i, j > 0 且 x(i) = y(j)
         └ max(c[i−1][j], c[i][j−1])      若 i, j > 0 且 x(i) ≠ y(j)

答案是 c[m][n]。

重疊子問題：為什麼不能直接遞迴

照遞迴式直接寫成遞迴函式，答案是對的，但會非常慢。最後兩個字元不同時，c(i, j) 會呼叫 c(i−1, j) 和 c(i, j−1)，而這兩個又都會呼叫 c(i−1, j−1)，同一個子問題被重算好幾次，越往下重複得越多。

最壞情況（完全沒有相同字元）下呼叫次數是 2·C(m+n, m) − 1，m = n = 10 時是 369,511 次；但不同的子問題只有 (m+1)(n+1) = 121 種。Overlapping Subproblems（重疊子問題）加上最佳子結構，正是適合用 Dynamic Programming（動態規劃，DP）的訊號：把每個子問題的答案存起來，算過的就不要再算。

做法有兩種：

  • Memoization（記憶化，由上而下）：保留遞迴的寫法，但先查表，算過就直接回傳。
  • Bottom-up（由下而上）：把子問題依「誰先需要誰」排好順序，用迴圈從小填到大，完全不用遞迴。下一節的填表法就是這種。

實際跑 STONE 和 LONGEST：單純遞迴呼叫了 829 次，記憶化只呼叫 50 次（約 6%）；換成 ABCDEFGHIJ 和 BADCFEHGJI，單純遞迴 8,341 次，記憶化 149 次，差了 56 倍，而且字串越長差距越大。

看程式碼：直接遞迴與記憶化
lcsMemo()：由上而下 + 記憶
int memo[MAX + 1][MAX + 1];
int lcsMemo(const char *X, const char *Y, int i, int j) {
  calls++;
  if (i == 0 || j == 0) return 0;
  if (memo[i][j] != -1) return memo[i][j];     /* 算過了，直接查表 */
  int r;
  if (X[i - 1] == Y[j - 1]) r = lcsMemo(X, Y, i - 1, j - 1) + 1;
  else {
    int up = lcsMemo(X, Y, i - 1, j), left = lcsMemo(X, Y, i, j - 1);
    r = up >= left ? up : left;
  }
  return memo[i][j] = r;
}
lcsNaive()：直接照遞迴式（指數時間）
int lcsNaive(const char *X, const char *Y, int i, int j) {
  calls++;
  if (i == 0 || j == 0) return 0;
  if (X[i - 1] == Y[j - 1]) return lcsNaive(X, Y, i - 1, j - 1) + 1;
  int up = lcsNaive(X, Y, i - 1, j), left = lcsNaive(X, Y, i, j - 1);
  return up >= left ? up : left;
}

由下而上填表

c[i][j] 只用到左上、上、左三格，所以只要一列一列、每列由左到右填，需要的格子一定都已經算好了。先把第 0 列和第 0 行全填 0（空字串和任何字串的 LCS 長度是 0），再從 c[1][1] 填到 c[m][n]。

為了之後能找出 LCS 本身，每一格順便記下它的值是從哪裡來的，存在 b[i][j]：

  • ↖：字元相同，值 = 左上 + 1。
  • ↑：字元不同，上面比較大（或平手），值 = 上面。
  • ←：字元不同，左邊比較大，值 = 左邊。

以 X = STONE、Y = LONGEST 為例，填完的表如下（每格是「箭頭 長度」）：

j = 0LONGEST
i = 000000000
S0↑ 0↑ 0↑ 0↑ 0↑ 0↖ 1← 1
T0↑ 0↑ 0↑ 0↑ 0↑ 0↑ 1↖ 2
O0↑ 0↖ 1← 1← 1← 1↑ 1↑ 2
N0↑ 0↑ 1↖ 2← 2← 2← 2↑ 2
E0↑ 0↑ 1↑ 2↑ 2↖ 3← 3← 3

幾個值得看的格子：

  • c[1][6]：S = S，左上是 0，所以 c = 1、箭頭 ↖。
  • c[3][2]：O = O，左上 c[2][1] = 0，所以 c = 1。
  • c[4][3]：N = N，左上 c[3][2] = 1，所以 c = 2，表示「STON 和 LON」的 LCS 是 ON。
  • c[5][5]：E = E，左上 c[4][4] = 2，所以 c = 3。
  • 右下角 c[5][7] = 3，就是答案。
看程式碼：lcsLength() 填表
lcsLength()：由下而上填 c 和 b
int lcsLength(const char *X, const char *Y) {
  int m = strlen(X), n = strlen(Y);
  for (int i = 0; i <= m; i++) c[i][0] = 0;   /* 空字串和任何字串的 LCS 長度都是 0 */
  for (int j = 0; j <= n; j++) c[0][j] = 0;
  for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++) {
      if (X[i - 1] == Y[j - 1]) {              /* 最後一個字元相同：一定可以接在 LCS 後面 */
        c[i][j] = c[i - 1][j - 1] + 1;
        b[i][j] = 'D';
      } else if (c[i - 1][j] >= c[i][j - 1]) { /* 不同：丟掉 X 的最後一個字元比較好（平手往上） */
        c[i][j] = c[i - 1][j];
        b[i][j] = 'U';
      } else {                                 /* 丟掉 Y 的最後一個字元比較好 */
        c[i][j] = c[i][j - 1];
        b[i][j] = 'L';
      }
    }
  return c[m][n];
}

動手操作

輸入兩個字串（X 最多 7 個字元、Y 最多 8 個），看表格一格一格填出來：橘色是正在填的格子，藍色是它參考的格子，綠色表示字元相同。表格填完後，會從右下角照箭頭往回走，紫色的格子就是 LCS 用到的字元。按「ABAB / BABA」再切換「平手時：往上／往左」，可以看到同樣長度 3、但內容不同的兩個 LCS。

找出 LCS：照箭頭走回去

c[m][n] 只告訴我們長度。要找出 LCS 本身，就從右下角 (m, n) 出發，照 b 的箭頭往回走：

  • 遇到 ↖：xi 是 LCS 的一個字元，記下來，往左上走。
  • 遇到 ↑ 或 ←：照箭頭走，不記字元。
  • 走到第 0 列或第 0 行就停。

因為是從字串尾巴往前找，字元出現的順序是反的。printLCS() 用遞迴解決這件事：先遞迴到左上，回來時再印，印出來就是正的順序。每走一步 i 或 j 至少減 1，所以回溯最多 m + n 步，時間 O(m + n)。

STONE、LONGEST 的路徑是 (5,7) ← (5,6) ← (5,5) ↖ (4,4) ← (4,3) ↖ (3,2) ↖ (2,1) ↑ (1,1) ↑ (0,1)，記下的字元依序是 E、N、O，反過來得到 ONE。

平手時往哪走，會影響找到哪一個 LCS

上面和左邊一樣大時，往上或往左都對，但會走到不同的路徑。表格的數字不受影響，只有箭頭不同，所以長度一定一樣，找到的 LCS 卻可能不同：

XYLCS 長度平手往上平手往左
ABABBABA3ABABAB
AABBCABCBA3ABBABC
STONELONGEST3ONEONE

考題通常會指定平手的規則（最常見的是「≥ 時往上」），沒有指定時，任何一個 LCS 都算對。

看程式碼：printLCS() 回溯
printLCS()：照箭頭走回去
void printLCS(const char *X, int i, int j) {
  if (i == 0 || j == 0) return;
  if (b[i][j] == 'D') {
    printLCS(X, i - 1, j - 1);
    putchar(X[i - 1]);
  } else if (b[i][j] == 'U') {
    printLCS(X, i - 1, j);
  } else {
    printLCS(X, i, j - 1);
  }
}
lcsLengthLeft()：平手時記 ←
int lcsLengthLeft(const char *X, const char *Y) {
  int m = strlen(X), n = strlen(Y);
  for (int i = 0; i <= m; i++) c[i][0] = 0;
  for (int j = 0; j <= n; j++) c[0][j] = 0;
  for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++) {
      if (X[i - 1] == Y[j - 1]) {
        c[i][j] = c[i - 1][j - 1] + 1;
        b[i][j] = 'D';
      } else if (c[i][j - 1] >= c[i - 1][j]) { /* 平手往左 */
        c[i][j] = c[i][j - 1];
        b[i][j] = 'L';
      } else {
        c[i][j] = c[i - 1][j];
        b[i][j] = 'U';
      }
    }
  return c[m][n];
}

複雜度與省空間

表格有 (m+1)(n+1) 格，每格只做一次比較和一次取最大值，都是 O(1)，所以：

  • 時間：填表 Θ(mn)，回溯 O(m + n)，總共 Θ(mn)。兩個長度 1000 的字串大約填一百萬格，一瞬間就算完；暴力法要 21000 個子序列。
  • 空間：c 和 b 各 (m+1)(n+1) 格，Θ(mn)。

如果只要長度、不要 LCS 本身，空間可以大幅節省：填第 i 列只需要第 i−1 列，所以只留兩列就夠，空間降到 O(n)；把較短的字串放在 Y，就是 O(min(m, n))。代價是沒有完整的 b 表，無法再回溯出 LCS。（只用 O(min(m, n)) 空間又要找出 LCS，需要更進階的分治技巧，考研很少考。）

看程式碼：lcsTwoRows() 只留兩列
lcsTwoRows()：O(n) 空間求長度
int lcsTwoRows(const char *X, const char *Y) {
  int m = strlen(X), n = strlen(Y);
  int prev[MAX + 1] = {0}, cur[MAX + 1] = {0};
  for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
      if (X[i - 1] == Y[j - 1]) cur[j] = prev[j - 1] + 1;
      else cur[j] = prev[j] >= cur[j - 1] ? prev[j] : cur[j - 1];
    }
    memcpy(prev, cur, sizeof prev);             /* 這一列變成下一輪的「上一列」 */
  }
  return prev[n];
}

由上而下 vs 由下而上

記憶化（由上而下）填表（由下而上）
寫法遞迴 + 查表，最接近遞迴式雙層迴圈，要自己決定填表順序
算哪些子問題只算真的用得到的全部 (m+1)(n+1) 格都算
額外成本遞迴呼叫、堆疊深度最多 m + n沒有遞迴，常數比較小
省空間不容易容易改成只留兩列

相關問題與 DP 的四個步驟

最長共同子字串

如果要求連續（子字串），遞迴式要改：字元不同時，連續的共同部分在這裡斷掉了，所以是 0 而不是取 max；答案也不是右下角，而是整張表的最大值。

L[i][j] = L[i−1][j−1] + 1     若 x(i) = y(j)
L[i][j] = 0                   若 x(i) ≠ y(j)
答案 = max over all i, j of L[i][j]

例如 ABABC 和 BABCA：最長共同子字串是 BABC（長度 4）。這組剛好 LCS 也是 BABC，但一般來說 LCS 長度 ≥ 最長共同子字串長度，因為子字串一定也是子序列。

其他用到 LCS 的地方

  • 最長遞增子序列（LIS）：把序列 A 排序並去掉重複得到 B，A 和 B 的 LCS 就是 A 的最長嚴格遞增子序列，時間 O(n²)。
  • Edit distance（編輯距離）：同樣是兩個字串的二維表，每格看左、上、左上三格，只是成本換成插入、刪除、替換的次數。
  • diff：兩份檔案以「行」為字元求 LCS，LCS 之外的行就是被新增或刪除的行。

設計 DP 的四個步驟：(1) 找出最佳解的結構（最佳子結構）；(2) 寫出遞迴式定義最佳值；(3) 由下而上（或記憶化）算出最佳值；(4) 用記錄下來的選擇回推出最佳解本身。LCS 對應的就是：比最後一個字元 → c[i][j] 的遞迴式 → 填表 → 照箭頭回溯。

考研重點：題型地圖

題型常見度解題步驟例題
填 c / b 表、求 LCS很常考先填第 0 列、第 0 行；逐列由左到右，相同取左上 + 1，不同取 max(上, 左)；從右下角照箭頭回溯例題 例題
子序列與子字串的定義常考子序列可跳著選、順序不變；子字串必須連續例題
時間、空間複雜度常考Θ(mn) 時間；只求長度可降到 O(min(m, n)) 空間例題
直接遞迴的呼叫次數偶爾寫出 T(m, n) = 1 + T(m−1, n) + T(m, n−1)，用格子路徑計數求解例題
證明最佳子結構常考剪貼論證：假設子問題不是最佳，換掉後得到更好的整體解，矛盾例題
變形：子字串、LIS常考子字串不同時歸 0、答案取全表最大；LIS 用排序後的序列做 LCS例題 例題

易錯點

  • 子序列要連續 → 子序列只要順序不變、可以跳著選；要連續的是子字串 例題
  • 字元不同時取 max(上, 左, 左上) → 左上一定 ≤ 上和左，看它沒有意義；不同時只比上和左 例題
  • LCS 是唯一的 → 長度唯一，內容不一定；平手往上或往左可能找到不同的 LCS 例題
  • 回溯時遇到 ↑、← 也要記字元 → 只有 ↖ 的格子對應 LCS 的字元，而且找到的順序是反的 例題
  • 只留兩列也能找出 LCS → 兩列版只能算長度，沒有完整的 b 表就無法回溯 例題
  • 最長共同子字串和 LCS 用同一個遞迴式 → 子字串在字元不同時要歸 0，答案取整張表的最大值而不是右下角 例題
