Linear Recurrence Relations 線性遞迴關係把「下一項怎麼來」變成「第 n 項是多少」

Ch5 Advanced Counting 難度 recurrence characteristic equation particular solution modeling

為什麼需要遞迴關係

很多計數問題很難一口氣寫出答案，但很容易說出「第 n 個答案和前面幾個答案的關係」。例如爬 n 階樓梯、每次走 1 階或 2 階，有幾種走法？直接列舉很快就爆炸，可是只要看最後一步：最後走 1 階，前面是爬 n−1 階的任何走法；最後走 2 階，前面是爬 n−2 階的任何走法。兩種情況不重疊、也沒有遺漏，所以走法數 an = an−1 + an−2。

像這樣用前面的項定義後面的項的式子，叫做 Recurrence Relation（遞迴關係）。光有遞迴式還不能決定整個數列，要再給開頭幾項，也就是 Initial Conditions（初始條件）：爬樓梯是 a1 = 1（只有「走 1」）、a2 = 2（「1+1」或「2」）。遞迴式加上初始條件，數列的每一項就唯一確定了。

遞迴式很適合「算出來」，但不適合「看出來」：想知道 a100 要先算前面 99 項，也看不出數列長多快。所以我們想把它化成 Closed Form（閉合式），也就是只用 n 寫出來的公式。爬樓梯的答案其實是 an = Fn+1（Fibonacci 數），閉合式裡有 φ = (1 + √5)/2 ≈ 1.618，代表每多一階，走法大約變成 1.618 倍；樓梯從 20 階變成 30 階，走法多了約 φ10 ≈ 123 倍。這種「成長率」的資訊只有閉合式才看得出來。

這一頁處理考研最常考的一類：常係數線性遞迴。內容分成三塊：(1) 從問題列出遞迴式與初始條件（建模）；(2) 用特徵方程式解齊次遞迴；(3) 用「齊次解 + 特解」解非齊次遞迴，最後代回前幾項驗算。

和演算法的分治遞迴式不同：T(n) = 2T(n/2) + n 這種「n 變成 n/b」的遞迴是在估計執行時間，通常只要 Θ 等級，用 Master Theorem 主定理解；這一頁的遞迴是「n 變成 n−1、n−2」，要求的是每一項的精確值。離散數學裡分治遞迴的精確解法放在 Divide-and-Conquer Recurrences 分治遞迴式（籌備中）。

用遞迴關係建模

建模的固定套路：把長度 n（或大小 n）的情況，依照最後一步（或第一步）分類，每一類去掉那一步後，剩下的是一個「同類但比較小」的問題。分類要做到不重疊、不遺漏，再把各類的個數加起來。最後一定要直接數出最小的幾項當初始條件，並用它們驗算遞迴式。

例 1：不含連續 00 的二進位字串

令 an 是長度 n、沒有出現 00 的 0/1 字串個數。看最後一個字元：

  • 最後是 1：前面 n−1 個字元只要自己合法就好，接上 1 不會產生 00，共 an−1 種。
  • 最後是 0：倒數第二個一定是 1（否則結尾是 00），所以字串長成「長度 n−2 的合法字串 + 10」，共 an−2 種。

所以 an = an−1 + an−2（n ≥ 3），初始條件直接數：長度 1 的 0、1 都合法，a1 = 2；長度 2 的 01、10、11 合法，a2 = 3。往下算得 5、8、13、21、…，和 Fibonacci 一樣的遞迴、但初始條件不同，所以 an = Fn+2。長度 12 時有 377 個合法字串，佔全部 4096 個的 9.2%，n 越大比例越小，因為合法字串的成長率是 φ ≈ 1.618，比全部字串的 2 慢。程式用暴力法數 n = 1～12 的每一個字串，結果和遞迴完全一致。

看程式碼：暴力法 vs 遞迴（不含 00 的字串）
no00Rec()：a(n) = a(n−1) + a(n−2)
long long no00Rec(int n) {                      /* a(1) = 2、a(2) = 3 */
  long long a = 2, b = 3;
  if (n == 1) return 2;
  for (int i = 3; i <= n; i++) { long long t = a + b; a = b; b = t; }
  return b;
}
no00Brute()：逐一檢查 2^n 個字串
long long no00Brute(int n) {
  long long cnt = 0;
  for (long long s = 0; s < (1LL << n); s++) {
    int ok = 1;
    for (int i = 0; i + 1 < n; i++)
      if (!((s >> i) & 1) && !((s >> (i + 1)) & 1)) { ok = 0; break; }
    cnt += ok;
  }
  return cnt;
}

例 2：河內塔

三根柱子 A、B、C，A 上有 n 個由大到小疊好的圓盤，每次搬一個、大的不能壓在小的上面，要全部搬到 C。令 H(n) 是最少步數。最大的圓盤要搬到 C，當下 C 必須是空的、其他 n−1 個必須全疊在 B，所以：

H(n) = 2H(n−1) + 1，H(1) = 1。這是一個非齊次遞迴（多了常數 1），後面會解出 H(n) = 2n − 1：64 個圓盤要 264 − 1 ≈ 1.8 × 1019 步，一秒一步要搬約 5850 億年。程式實際遞迴搬一次，n = 1～10 的步數都等於 2n − 1。

看程式碼：hanoiMoves() 實際搬一次數步數
hanoiMoves()：H(n) = 2H(n−1) + 1
long long hanoiMoves(int n, int from, int to, int via) {
  if (n == 0) return 0;
  long long m = hanoiMoves(n - 1, from, via, to);  /* 上面 n−1 個先移到中間 */
  m += 1;                                          /* 最大的一個移到目標 */
  return m + hanoiMoves(n - 1, via, to, from);     /* n−1 個再疊上去 */
}

例 3：兔子與鋪磚

  • 兔子：一對剛出生的兔子第二個月起每月生一對，新生的也一樣，兔子不死。第 n 個月的對數 = 上個月的對數（全部還活著）+ 兩個月前的對數（它們這個月都已成熟、各生一對），又是 fn = fn−1 + fn−2，f1 = f2 = 1。這就是 Fibonacci 數列的由來。
  • 2 × n 鋪磚：用 2×1 的磚和 2×2 的方磚鋪滿 2 × n 的長條。看最右邊：直放一塊 2×1，剩 2 × (n−1)；或是兩塊橫放、或是一塊 2×2，這兩種都佔掉寬度 2，剩 2 × (n−2)。所以 an = an−1 + 2an−2，a0 = a1 = 1。「2an−2」的 2 代表寬度 2 的收尾有兩種不同的鋪法。

例 4：會產生非齊次項的建模

長度 n 的三進位字串（字元是 0、1、2），含有偶數個 0 的有幾個？看最後一個字元：最後是 1 或 2（兩種），前面 n−1 個要有偶數個 0，共 2an−1；最後是 0，前面要有奇數個 0，而奇數個 0 的字串 = 全部 3n−1 減掉偶數個的 an−1。合起來 an = 2an−1 + (3n−1 − an−1) = an−1 + 3n−1，a1 = 2。用「全部減掉補集」來表示另一類，是這類題目的關鍵，也因此多出一個 3n−1 的非齊次項。

線性、常係數、齊次、階數

解法能不能用，取決於遞迴式的形式。這一頁處理的是：

a(n) = c1·a(n−1) + c2·a(n−2) + … + ck·a(n−k) + f(n)，   ck ≠ 0
  • 線性（linear）：每個 an−i 都是一次方，沒有 an−12、an−1·an−2 這種項。
  • 常係數（constant coefficients）：c1, …, ck 是常數，不能和 n 有關（an = n·an−1 就不是）。
  • 階數（degree / order）：用到最遠的前 k 項，就是 k 階；要有 k 個初始條件才能決定數列。注意 ck ≠ 0，an = an−1 + 0·an−2 只是 1 階。
  • 齊次（homogeneous）：f(n) = 0，每一項都含 a；有 f(n) ≠ 0（常數、多項式、指數）就是非齊次。
遞迴式線性常係數？齊次？階數
an = an−1 + 2an−2是是2
Hn = 2Hn−1 + 1是否（多了常數 1）1
an = an−1 + 3n−1是否（多了 3n−1）1
an = 2an−1 − an−3是是3（中間的 an−2 係數是 0）
an = n·an−1否（係數和 n 有關）——
an = an−12 + 1否（平方，非線性）——

「線性」最重要的後果是疊加原理：如果 sn、tn 都滿足齊次遞迴，那麼任何線性組合 A·sn + B·tn 也滿足，因為把兩條等式分別乘 A、B 相加就得到了。所以只要找到 k 個「夠不一樣」的基本解，所有解都是它們的線性組合，剩下的只是用 k 個初始條件決定 k 個係數。整套解法就建立在這件事上；遇到非線性的遞迴（例如 Josephus 問題那種依奇偶分段的式子），這套方法就不能直接用，要回到歸納或觀察規律。

題目給的式子不一定長成標準形：an+2 − 5an+1 + 6an = 2 只是把下標整體平移 2，等價於 an = 5an−1 − 6an−2 + 2；2an = 7an−1 − 6an−2 要先同除 2，首項係數變成 1 再寫特徵方程式（或直接寫 2r2 − 7r + 6 = 0，根一樣）。

特徵方程式：相異根

1 階齊次 an = c·an−1 是等比數列，解是 an = a0·cn。受到啟發，對 k 階齊次遞迴也猜 an = rn（r ≠ 0）代進去：

r^n = c1·r^(n−1) + c2·r^(n−2)        兩邊同除 r^(n−2)
r^2 − c1·r − c2 = 0                   ← 特徵方程式（characteristic equation）

這條方程式叫 Characteristic Equation（特徵方程式），它的根叫 Characteristic Root（特徵根）。r 是特徵根 ⟺ rn 滿足齊次遞迴。寫特徵方程式的口訣：把 an−i 換成 rk−i，全部移到同一邊，所以遞迴式裡的 +c 會變成 −c。

定理：兩個相異根

若 r2 − c1r − c2 = 0 有兩個相異根 r1 ≠ r2，則所有解都是

a(n) = A·r1^n + B·r2^n

A、B 由初始條件決定：代 n = 0、1 得 A + B = a0、A·r1 + B·r2 = a1。因為 r1 ≠ r2，這組聯立一定有唯一解：A = (a1 − r2a0)/(r1 − r2)、B = (r1a0 − a1)/(r1 − r2)。考題有時不給數字，只寫 a0 = A、a1 = B，要你寫出一般式，就是這兩條公式。

完整例子：2 × n 鋪磚

解 an = an−1 + 2an−2，a0 = a1 = 1：

步驟做什麼結果
1寫特徵方程式（全部移到同一邊）r2 − r − 2 = 0
2求根：判別式 D = 1 + 8 = 9 = 32r = (1 ± 3)/2 = 2、−1（相異）
3寫通解an = A·2n + B·(−1)n
4代初始條件n = 0：A + B = 1；n = 1：2A − B = 1
5解聯立A = 2/3、B = 1/3
6閉合式an = (2n+1 + (−1)n)/3
7驗算 n = 2、3（不是初始條件的項）遞迴 1 + 2 = 3、3 + 2 = 5；公式 (8 + 1)/3 = 3、(16 − 1)/3 = 5

係數 2/3、1/3 是分數，但每一項 an 都是整數：2n+1 除以 3 的餘數是 2 或 1，剛好被 (−1)n 補成 3 的倍數。這是一個好的檢查點：計數問題的閉合式代任何 n 都要是非負整數。從閉合式也看得出成長率：(−1)n/3 的絕對值不超過 1/3，an 基本上就是 2n+1/3，寬度每加 1，鋪法約變 2 倍。2 × 10 的長條有 (211 + 1)/3 = 683 種鋪法。

無理根也一樣：Fibonacci

Fn = Fn−1 + Fn−2，F0 = 0、F1 = 1。特徵方程式 r2 − r − 1 = 0，D = 5 不是完全平方數，根是 φ = (1 + √5)/2 ≈ 1.618 和 ψ = (1 − √5)/2 ≈ −0.618。步驟完全一樣，代公式得 A = 1/√5、B = −1/√5：

F(n) = (φ^n − ψ^n) / √5        （Binet 公式）

|ψ| < 1，所以 ψn/√5 的絕對值永遠小於 0.5 而且越來越小：Fn 就是 φn/√5 四捨五入。這就是「主導根」的觀念：絕對值最大的特徵根決定數列的成長率，其他根只貢獻越來越不重要的修正。

看程式碼：roots2() 求 2 階特徵根、recurTerms() 直接算前 N 項
roots2()：判別式判斷相異、重根、非整數根
int roots2(long long c1, long long c2, long long r[2]) {
  long long D = c1 * c1 + 4 * c2;             /* 判別式 */
  if (D < 0) return 0;                         /* 共軛複根 */
  long long s = (long long)sqrt((double)D);
  while (s * s > D) s--;
  while ((s + 1) * (s + 1) <= D) s++;
  if (s * s != D) return 0;                    /* D 不是完全平方數：無理根 */
  r[0] = (c1 + s) / 2;                         /* D 和 c1² 同奇偶，所以一定整除 */
  r[1] = (c1 - s) / 2;
  return D == 0 ? 1 : 2;
}
recurTerms()：照遞迴關係算前 N 項
void recurTerms(const Rec *R, long long a[], int N) {
  for (int n = 0; n < N; n++) {
    if (n < R->k) { a[n] = R->init[n]; continue; }   /* 前 k 項是初始條件 */
    long long v = fval(R, n);
    for (int i = 1; i <= R->k; i++) v += R->c[i] * a[n - i];
    a[n] = v;
  }
}

重根、高階與共軛複根

重根：要補 n·rn

如果特徵方程式是重根 r0（D = 0），只得到一個基本解 r0n。寫成 A·r0n + B·r0n = (A + B)r0n 其實只有一個自由度，兩個初始條件通常湊不出來。少掉的那個解是 n·r0n：

重根 r0：a(n) = (A + B·n)·r0^n

為什麼 n·r0n 是解？重根代表 r2 − c1r − c2 = (r − r0)2，比較係數得 c1 = 2r0、c2 = −r02。代進右邊：c1(n−1)r0n−1 + c2(n−2)r0n−2 = 2(n−1)r0n − (n−2)r0n = n·r0n，正好等於左邊。

例：an = 4an−1 − 4an−2，a0 = 3、a1 = 4。特徵方程式 r2 − 4r + 4 = (r − 2)2，重根 2。an = (A + Bn)2n；n = 0 得 A = 3，n = 1 得 2(3 + B) = 4，B = −1。所以 an = (3 − n)·2n：3、4、4、0、−16、−64、…。n = 3 時剛好是 0，之後變負數，這是 (3 − n) 這個因子造成的，單看 2n 想不到；用遞迴驗算 a3 = 4·4 − 4·4 = 0，一致。

一般規則與 3 階

k 階遞迴的特徵方程式是 k 次：rk − c1rk−1 − … − ck = 0。每個 m 重根 r 提供 m 個基本解 rn、n·rn、…、nm−1·rn，所有根的重數加起來剛好 k，所以基本解剛好 k 個、對應 k 個初始條件。

3 次方程式沒有好用的公式，考題的根幾乎都是整數，用有理根定理找：首項係數是 1 時，整數根一定整除常數項。找到一個根 t 就用綜合除法除掉 (r − t)，降成 2 次再用公式解；同一個 r 能連續除兩次就是重根。例：an = 2an−1 + an−2 − 2an−3，特徵方程式 r3 − 2r2 − r + 2 = 0，候選 ±1、±2，代入發現 1、−1、2 都是根，所以 an = A + B(−1)n + C·2n。若 a0, a1, a2 = 3, 2, 6，三元聯立 A + B + C = 3、A − B + 2C = 2、A + B + 4C = 6，解得 A = B = C = 1，an = 1 + (−1)n + 2n。

重根和 3 階混在一起時，例如特徵方程式 (r − 1)(r − 2)2 = 0，通解是 A + (B + Cn)·2n：1 是單根給 1 個，2 是 2 重根給 2 個，合計 3 個。

共軛複根（了解即可）

D < 0 時兩根是共軛複數 ρe±iθ。公式 A·r1n + B·r2n 仍然成立，只是 A、B 是複數；用 Euler 公式重新組合，可以寫成全部是實數的形式 ρn(A cos nθ + B sin nθ)。例：an = 2an−1 − 2an−2，a0 = 1、a1 = 2。r2 − 2r + 2 = 0，根 1 ± i，ρ = √2、θ = 45°；代初始條件得 A = 1、B = 1，an = (√2)n(cos 45°n + sin 45°n)。數列是 1、2、2、0、−4、−8、−8、0、16、…：cos、sin 讓正負號每 8 項繞一圈，(√2)n 讓絕對值每 8 項乘 16。考研很少要求寫到這一步，知道「複根會讓數列振盪」就夠。

看程式碼：charRoots() 求特徵根與重數
charRoots()：2 階用判別式，3 階用有理根定理加綜合除法
int charRoots(Rec *R) {
  R->nr = 0;
  if (R->k == 2) {
    long long r[2];
    int t = roots2(R->c[1], R->c[2], r);
    if (t == 0) return 0;
    R->root[0] = r[0]; R->mult[0] = t == 1 ? 2 : 1;
    if (t == 2) { R->root[1] = r[1]; R->mult[1] = 1; }
    R->nr = t;
    return 1;
  }
  long long poly[4], deg = R->k, ck = R->c[R->k] < 0 ? -R->c[R->k] : R->c[R->k];
  poly[0] = 1;                                 /* poly[i] 是 r^(deg-i) 的係數 */
  for (int i = 1; i <= R->k; i++) poly[i] = -R->c[i];
  for (long long r = -ck; r <= ck && deg > 0; r++) {
    if (r == 0 || ck % r != 0) continue;
    int m = 0;
    for (;;) {
      long long b[4], acc = 0;                 /* 綜合除法：餘數 acc = poly(r) */
      for (int i = 0; i <= deg; i++) { acc = acc * r + poly[i]; b[i] = acc; }
      if (acc != 0) break;
      for (int i = 0; i < deg; i++) poly[i] = b[i];
      deg--; m++;
      if (deg == 0) break;
    }
    if (m) { R->root[R->nr] = r; R->mult[R->nr] = m; R->nr++; }
  }
  return deg == 0;                             /* 全部降完才表示根都是整數 */
}

非齊次：齊次解加特解

非齊次遞迴 an = c1an−1 + … + ckan−k + f(n) 去掉 f(n) 後的式子叫對應的齊次遞迴。關鍵定理：

通解 = 對應齊次遞迴的通解 a(n)^(h)  +  任意一個特解 a(n)^(p)

證明只要一行：如果 pn、qn 都滿足非齊次遞迴，兩式相減時 f(n) 消掉，所以 qn − pn 滿足齊次遞迴，也就是 qn = pn + （某個齊次解）。所以只要找到一個 Particular Solution（特解），其他所有解都是「它 + 齊次解」。

特解怎麼猜

特解用 Method of Undetermined Coefficients（待定係數法）：照 f(n) 的樣子猜一個帶未知係數的形式，代進遞迴比較兩邊，解出係數。設 f(n) = P(n)·sn，P(n) 是 d 次多項式（純多項式就是 s = 1）：

f(n)s 不是特徵根s 是 m 重特徵根
常數 C（s = 1、d = 0）uu·nm
d 次多項式（s = 1）u0 + u1n + … + udndnm(u0 + … + udnd)
C·snu·snu·nm·sn
(d 次多項式)·sn(u0 + … + udnd)·snnm(u0 + … + udnd)·sn
  • 多項式要猜「完整的」同次多項式：f(n) = 3n 也要猜 u0 + u1n，不能只猜 u1n，因為代進去常數項會跑出來。
  • 為什麼重複時要乘 nm：如果 s 是特徵根，u·sn 本身就是齊次解，代進去左邊是 0，永遠等不到 f(n)。乘一次 n 還不夠時（重根）就再乘，直到不再是齊次解，次數剛好是重數 m。常數的情況也一樣：特徵根有 1 時，「常數」其實是 1n，要乘 n。
  • f(n) 有好幾項，例如 2n + 3n：依底數分開，每一項各猜一個特解再相加（疊加），每一項各自檢查要不要乘 nm。

例 1：多項式，沒有重複

an = 5an−1 − 6an−2 + 2n + 7，a0 = 10、a1 = 15。

步驟做什麼結果
1齊次部分的特徵方程式r2 − 5r + 6 = 0，r = 3、2
2齊次通解A·3n + B·2n
3f(n) = 2n + 7 是 1 次多項式，s = 1 不是根猜 pn = u + vn
4代入：u + vn = 5(u + v(n−1)) − 6(u + v(n−2)) + 2n + 7n 的係數：v = −v + 2，v = 1；常數項：u = −u + 7v + 7，u = 7
5通解 = 齊次 + 特解an = A·3n + B·2n + n + 7
6代初始條件（特解要一起代）A + B + 7 = 10；3A + 2B + 8 = 15 → A = 1、B = 2
7閉合式並驗算 n = 2an = 3n + 2n+1 + n + 7；9 + 8 + 9 = 26，遞迴 5·15 − 6·10 + 11 = 26

步驟 4 的常數項細算：右邊常數 = 5(u − v) − 6(u − 2v) + 7 = −u + 7v + 7，令它等於左邊的 u，得 2u = 7v + 7 = 14，u = 7。另一個直覺的檢查：f(n) 是 2n + 7，特解 n + 7 也是 1 次，次數對得上。

例 2：指數，和特徵根重複

an = 3an−1 + 4an−2 + 5·4n，a0 = 3、a1 = 23。特徵方程式 r2 − 3r − 4 = (r − 4)(r + 1)，根 4、−1。f(n) 的底數 4 剛好是 1 重根，所以猜 u·n·4n 而不是 u·4n。代入並同除 4n−2：

16u·n = 12u·(n−1) + 4u·(n−2) + 80
16u·n = 16u·n − 20u + 80      → n 的項兩邊抵消，剩 20u = 80，u = 4

n 的項兩邊剛好抵消，正是「4n 是齊次解」造成的；如果當初猜 u·4n，代進去會得到 0 = 80，無解，這就是忘記乘 n 時會看到的訊號。特解 4n·4n，通解 A·4n + B(−1)n + 4n·4n；代 a0：A + B = 3，代 a1：4A − B + 16 = 23，得 A = 2、B = 1：

a(n) = (2 + 4n)·4^n + (−1)^n

驗算 n = 2：(2 + 8)·16 + 1 = 161，遞迴 3·23 + 4·3 + 80 = 161，一致。河內塔 H(n) = 2H(n−1) + 1 也是同一套：根 2，常數項的底數 1 不是根，猜常數 u，u = 2u + 1 得 u = −1，H(n) = A·2n − 1，H(1) = 1 得 A = 1，H(n) = 2n − 1。反過來，如果特徵根有 1（例如 an = 4an−1 − 3an−2 + 常數，根 3、1），常數項就要猜 u·n。

看程式碼：particular() 猜特解、solveCoef() 解係數
particular()：猜 n^m (q0 + q1 n + …) s^n 並解出 q
void particular(Rec *R, int t) {
  Term *T = &R->f[t];
  int m = multiplicity(R, T->s), d = T->d, k = R->k;
  Frac M[MAXV][MAXV], v[MAXV];
  for (int e = 0; e <= d; e++) {              /* 代 n = k, k+1, ..., k+d，得到 d+1 條方程式 */
    long long n = k + e;
    for (int j = 0; j <= d; j++) {            /* q_j 的係數：s^k n^(m+j) − Σ c_i s^(k−i) (n−i)^(m+j) */
      long long coef = ipow(T->s, k) * ipow(n, m + j);
      for (int i = 1; i <= k; i++) coef -= R->c[i] * ipow(T->s, k - i) * ipow(n - i, m + j);
      M[e][j] = F(coef, 1);
    }
    v[e] = F(ipow(T->s, k) * polyAt(T, n), 1);   /* 兩邊同除 s^(n−k) */
  }
  R->pm[t] = m;
  gauss(d + 1, M, v, R->q[t]);
}
solveCoef()：初始條件扣掉特解，解 k 元聯立
void solveCoef(Rec *R) {
  Frac M[MAXV][MAXV], v[MAXV];
  for (int n = 0; n < R->k; n++) {
    int col = 0;
    for (int i = 0; i < R->nr; i++)
      for (int e = 0; e < R->mult[i]; e++)    /* m 重根 r 提供 r^n, n r^n, ..., n^(m-1) r^n */
        M[n][col++] = F(ipow(n, e) * ipow(R->root[i], n), 1);
    v[n] = fsub(F(R->init[n], 1), partAt(R, n));
  }
  gauss(R->k, M, v, R->A);
}

動手操作

在上方輸入係數 c1, c2（3 階再加 c3）、非齊次項 f(n)（例如 2n+7、5*4^n、n*2^n、2^n+3^n，齊次填 0）和初始條件 a0, a1（, a2），按「求解」。動畫依序列出特徵方程式、根（藍色是相異根、紫色是重根、青色是無理或複數根）、齊次通解、特解（和特徵根重複時會用紅字標出要乘幾次 n）、通解、聯立方程式與閉合式，最後把遞迴算出的前 8 項和閉合式逐項比對，綠色表示一致。3 階只處理整數根；2 階的無理根和共軛複根會用浮點數比對。

驗證答案與估計大小

代回前幾項

解遞迴的步驟多、符號多，任何一步錯了最後都會得到一個「看起來很合理」的錯答案。最便宜的檢查是：用遞迴算出 ak、ak+1，再用閉合式算一次，兩邊要相等。只代 n = 0、1 沒有用，因為係數本來就是照它們解的，一定對；有檢查力的是初始條件以外的項。在考場上代一項通常只要 30 秒，卻能抓到大部分的錯，例如特徵方程式的正負號寫反、特解忘記乘 n、解聯立時漏了特解。

另外兩個快速檢查：(1) 特解單獨代回非齊次遞迴要成立（不用管初始條件）；(2) 計數題的閉合式代任何 n 都要是非負整數，算出分數或負數就一定有錯。

看程式碼：solve() 串起所有步驟、verify() 逐項比對
verify()：遞迴值和閉合式逐項相等
int verify(const Rec *R, int N) {
  long long a[40];
  recurTerms(R, a, N);
  for (int n = 0; n < N; n++) {
    Frac c = closedAt(R, n);
    if (c.q != 1 || c.p != a[n]) return 0;
  }
  return 1;
}
solve()：求根 → 特解 → 係數
int solve(Rec *R) {
  if (!charRoots(R)) return 0;                 /* 1. 特徵方程式的根與重數 */
  for (int t = 0; t < R->nf; t++)              /* 2. 每一種 s^n 各猜一個特解（疊加） */
    particular(R, t);
  solveCoef(R);                                /* 3. 用初始條件解齊次解的係數 */
  return 1;
}

浮點數的陷阱

根是無理數時，用程式代閉合式會有誤差。用 double 算 Binet 公式 (φn − ψn)/√5 再四捨五入，n = 71 開始就和真正的 Fibonacci 數不同；換成 long double 撐到 n = 89，n = 90 也出錯了。原因是 double 只有約 16 位有效數字，φ 本身就帶著相對誤差，φn 把誤差放大到約 n 倍，F71 ≈ 3.1 × 1014 時絕對誤差已經超過 0.5。所以要精確值就用整數照遞迴算（unsigned long long 可以精確算到 F93），閉合式拿來分析成長率、估計大小。

看程式碼：Binet 公式用浮點數算到第幾項開始錯
binetFailDouble()：double 版本
int binetFailDouble(void) {
  unsigned long long a = 0, b = 1;              /* 精確的 F(n)、F(n+1) */
  double phi = (1 + sqrt(5.0)) / 2, psi = (1 - sqrt(5.0)) / 2;
  for (int n = 0; n <= 92; n++) {
    double v = (pow(phi, n) - pow(psi, n)) / sqrt(5.0);
    if ((unsigned long long)llround(v) != a) return n;
    unsigned long long t = a + b; a = b; b = t;
  }
  return -1;
}
binetFailLong()：long double 版本
int binetFailLong(void) {
  unsigned long long a = 0, b = 1;
  long double r5 = sqrtl(5.0L), phi = (1 + r5) / 2, psi = (1 - r5) / 2;
  for (int n = 0; n <= 92; n++) {
    long double v = (powl(phi, n) - powl(psi, n)) / r5;
    if ((unsigned long long)llroundl(v) != a) return n;
    unsigned long long t = a + b; a = b; b = t;
  }
  return -1;
}

估計「第一個超過某值的 n」

有了閉合式，就能回答「an 什麼時候超過 106」這類問題。做法是先抓主導項，用對數估出大概的 n，再用精確值確認邊界附近的兩項。以 an = (2 + 4n)·4n + (−1)n 為例：(−1)n 只是 ±1 可以忽略，(2 + 4n) 是多項式、成長得比 4n 慢很多。估 4n·4n ≈ 106：n = 7 時 30·47 = 491,520，還差約一半；n = 8 時 34·48 = 2,228,224，已經超過。精確值 a7 = 491,519、a8 = 2,228,225，所以答案是 n = 8。注意多項式因子不能直接丟掉：只看 4n ≈ 106 會估出 n ≈ 10，差了兩項。

和其他方法的關係

  • Generating Functions 生成函數（籌備中）：令 G(x) = Σ anxn，把遞迴式乘 xn 加總，可以解出 G(x) 是一個有理函數，分母正好是 1 − c1x − c2x2 = (1 − r1x)(1 − r2x)，r1、r2 就是特徵根。部分分式 A/(1 − r1x) + B/(1 − r2x) 展開後第 n 項係數就是 A·r1n + B·r2n，和特徵方程式法的 A、B 完全相同。考題常把兩種方法放在連續兩小題，用這個對應可以互相驗算：分母的根是特徵根的倒數。
  • Mathematical Induction 數學歸納法（籌備中）：題目只要求「證明 an = 某公式」時，不必從頭解，用強歸納法：檢查前 k 項，再假設 n−1、…、n−k 成立，代進遞迴推出 n 成立。代回前幾項驗算，其實就是歸納法的基底。
  • 分治遞迴式：T(n) = aT(n/b) + f(n) 不是這一頁的形式（n 是除的不是減的）。令 n = bm、tm = T(bm)，就會變成 tm = a·tm−1 + f(bm)，可以用這一頁的方法解精確值；只要漸近等級時用 Master Theorem 主定理比較快。
  • 聯立遞迴：好幾個數列互相定義（例如 xn、yn 互相引用）時，先消去其他數列，得到其中一個數列自己的高階線性遞迴，再用特徵方程式解。

一句話記住整套流程：建模列式 → 特徵方程式求根 → 寫齊次通解（重根乘 n）→ 照 f(n) 猜特解（和根重複乘 nm）→ 齊次 + 特解一起代初始條件 → 代 n = k 驗算。

易錯點

  • 特徵方程式照抄係數：an = −an−1 + 6an−2 寫成 r2 − r + 6 = 0 → 要全部移到同一邊：r2 + r − 6 = 0，根 2、−3；遞迴式的 +c 在特徵方程式變 −c 例題
  • 首項係數不是 1 也直接寫 r2 − 7r + 6 → 2an = 7an−1 − 6an−2 的特徵方程式是 2r2 − 7r + 6 = 0（或先同除 2） 例題
  • 重根寫成 A·rn + B·rn → 那只有一個自由度；重根要寫 (A + Bn)·rn，m 重根到 nm−1 例題
  • f(n) = C·sn 一律猜 u·sn → s 是特徵根時 u·sn 會被齊次部分消掉，要乘 n；常數項遇到特徵根 1 也一樣 例題 例題
  • 和重根重複時只乘一次 n → 乘 nm，m 是重數；2n 遇到 2 重根 2 要猜 u·n2·2n 例題
  • 先用初始條件解出齊次解的 A、B，再把特解加上去 → 初始條件是整個解要滿足的；要先寫好「齊次 + 特解」，再一起代入解 A、B 例題
  • 多項式 f(n) = 3n 只猜 un → 要猜完整的同次多項式 u + vn，代入後常數項也要對得上 例題
  • 初始條件隨便寫成 Fibonacci 的 1、1 → 同一個遞迴、不同初始條件就是不同數列；一定要直接數最小的幾項（例如不相鄰的排法 a1 = 2、a2 = 3） 例題
