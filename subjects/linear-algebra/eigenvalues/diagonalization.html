Diagonalization 對角化找 n 個線性獨立的特徵向量排成 P，A = PDP⁻¹，Aᵏ、矩陣函數、遞迴式都變成對角線上各算各的

Ch6 Eigenvalues 難度 diagonalizable PDP⁻¹ multiplicity matrix power similarity

為什麼要對角化

對角矩陣是最好算的矩陣：D = diag(2, 5) 乘一個向量，就是第 1 個分量乘 2、第 2 個分量乘 5，各管各的；D100 就是 diag(2100, 5100)，一步寫完；det D 是對角線乘積，D 的特徵值就寫在對角線上。一般的矩陣沒有這麼好的性質，A100 硬乘要做 99 次矩陣乘法，而且看不出 A 長期會把向量帶到哪裡。

Diagonalization（對角化）的想法是：換一組座標軸來看 A。如果能找到 n 個線性獨立的特徵向量，拿它們當新的座標軸，A 在每個軸上都只是「乘以一個倍數」，在這組座標下 A 就變成對角矩陣。寫成矩陣就是

A = P D P⁻¹      （P 的行是特徵向量，D 的對角線是對應的特徵值）

有了這個分解，很多原本麻煩的計算都變成「對角線上各算各的」：

  • 高次方：Ak = P Dk P−1，不管 k 是 12 還是 2004，都只要兩次矩陣乘法。考古題最愛出「A20 某個元素 mod 5」這種題。
  • 矩陣函數：多項式 p(A)、eA、平方根、立方根，都可以寫成 P f(D) P−1。
  • 長期行為：xk = Akx0 當 k → ∞ 會不會收斂，只看特徵值的絕對值是大於、等於還是小於 1。
  • 線性遞迴：Fibonacci 這類遞迴式可以寫成 uk+1 = Auk，對角化之後直接得到封閉式。

這一頁接在 特徵值與特徵向量 之後：特徵值、特徵向量怎麼求、代數重數和幾何重數的定義都在那一頁，這裡只簡短帶過，重點放在什麼時候可以對角化、P 和 D 怎麼組、Ak 與矩陣函數、遞迴式和相似矩陣的性質。

定義：A = PDP⁻¹ 與 AP = PD

定義：n×n 矩陣 A 稱為 diagonalizable（可對角化），如果存在可逆矩陣 P 和對角矩陣 D 使得 A = PDP−1（等價地 P−1AP = D）。這時說 P 把 A 對角化。

為什麼 P 的行一定是特徵向量

A = PDP−1 兩邊右乘 P，得到 AP = PD。把 P 寫成行向量 P = [v1 v2 ⋯ vn]，D = diag(λ1, …, λn)，兩邊逐行比較：

  • AP 的第 j 行 = A 乘上 P 的第 j 行 = Avj。
  • PD 的第 j 行 = P 的各行用 D 的第 j 行當係數組合，而 D 的第 j 行只有第 j 個位置是 λj，所以是 λjvj。

於是 AP = PD 正好等於 n 條式子 Avj = λjvj（j = 1, …, n）。P 可逆代表 vj 都不是零向量而且線性獨立，所以：

A 可對角化 ⟺ A 有 n 個線性獨立的特徵向量。P 的第 j 行放第 j 個特徵向量，D 的第 j 個對角元素放它的特徵值，兩者的順序必須對應。

例子

A = [4 1; 2 3]（第一列 4 1、第二列 2 3）。tr A = 7、det A = 10，特徵方程式 λ2 − 7λ + 10 = (λ − 2)(λ − 5) = 0，特徵值 2、5（求法見 特徵多項式）。解 (A − 2I)x = 0 得 v1 = (−1, 2)，解 (A − 5I)x = 0 得 v2 = (1, 1)，所以

P = [−1  1]     D = [2  0]     P⁻¹ = [−1/3  1/3]
    [ 2  1]         [0  5]           [ 2/3  1/3]

驗算 PDP−1：PD = [−2 5; 4 5]，再乘 P−1 得 [−2·(−1/3) + 5·(2/3), −2·(1/3) + 5·(1/3); 4·(−1/3) + 5·(2/3), 4·(1/3) + 5·(1/3)] = [4 1; 2 3]，正好回到 A。實務上驗算 AP = PD 比驗算 PDP−1 快，因為不用求反矩陣，每一行就是一次 Av = λv。

P、D 不唯一

  • 特徵向量可以乘非零倍數：P 的第 1 行換成 (1, −2) 或 (−3, 6) 都可以，D 不變。
  • 順序可以換：P = [1 −1; 1 2]（兩行對調）配 D = diag(5, 2) 也成立。但只換 D 不換 P 就錯了：P·diag(5, 2)·P−1 = [3 −1; −2 4] ≠ A。
  • 重根時選擇更多：特徵空間是 2 維以上時，裡面任何一組基底都可以當那幾行，這就是有的考古題 P 裡會留一個自由參數的原因。

唯一確定的是：D 的對角線（不計順序）一定是 A 的全部特徵值、照代數重數重複出現，因為 D 和 A 有相同的特徵多項式（下面「相似矩陣」一節）。

可對角化的判準：代數重數與幾何重數

「有 n 個獨立特徵向量」要怎麼檢查？特徵向量是一個特徵空間一個特徵空間求出來的，所以要數每個特徵空間的維度。回顧兩種重數（定義見 代數重數與幾何重數）：

  • Algebraic Multiplicity（代數重數） a(λ)：(λ − λ0) 在特徵多項式裡出現的次數。所有 a(λ) 加起來 = n。
  • Geometric Multiplicity（幾何重數） g(λ) = dim Eλ = n − rank(A − λI)。永遠有 1 ≤ g(λ) ≤ a(λ)。

不同特徵空間的基底合在一起仍然線性獨立（這是「相異特徵值的特徵向量線性獨立」的推廣），所以能湊出的獨立特徵向量總數就是 Σ g(λ)。要湊滿 n 個，而每個 g(λ) 又不能超過 a(λ)、Σ a(λ) = n，只有一種可能：每一個 g(λ) 都等於 a(λ)。

判準：A 可對角化 ⟺ 特徵多項式能分解成一次因式（在考慮的數系裡），而且每個特徵值的幾何重數 = 代數重數 ⟺ Σ dim Eλ = n。

情況結論理由
n 個相異特徵值一定可對角化每個 a(λ) = 1，而 1 ≤ g ≤ a 逼得 g = 1。這是充分條件，不是必要條件
有重根 λ0，rank(A − λ0I) = n − a(λ0)這個特徵值沒問題g = n − rank = a。例如 In：λ = 1 重數 n，rank(I − I) = 0，g = n
有重根 λ0，rank(A − λ0I) > n − a(λ0)不能對角化g < a，少的特徵向量別的特徵值補不回來，稱為 Defective Matrix（缺陷矩陣）
實矩陣有複數特徵值在 ℝ 上不能，在 ℂ 上可能可以旋轉 [0 −1; 1 0] 特徵值 ±i 相異：在 ℂ 上可對角化，P、D 要用複數

實際判斷的步驟

  1. 求特徵多項式並分解，得到每個特徵值和代數重數。
  2. 單根不用檢查（幾何重數一定是 1）。只對重根 λ0 算 rank(A − λ0I)，看 n − rank 是否等於代數重數。
  3. 全部相等就可對角化，接著求每個特徵空間的基底組 P；有一個不等就停，答「不可對角化」並寫出是哪個特徵值缺了幾個特徵向量。

例子：下面兩個矩陣的特徵多項式都是 −(λ − 1)(λ − 3)2，只差在 λ = 3 的 rank：

AA − 3Irankg(3)結論
[2 1 −1; −1 4 −1; −2 2 1][−1 1 −1; −1 1 −1; −2 2 −2]（三列成比例）13 − 1 = 2 = a(3)可對角化
[1 2 −1; −2 5 −1; −2 2 1][−2 2 −1; −2 2 −1; −2 2 −2]23 − 2 = 1 < a(3) = 2不可對角化

看 rank 時常用的捷徑：A − λ0I 的各列都成比例 ⇒ rank 1；上三角而且對角線全相同的矩陣（例如 [2 1; 0 2]、對角全 1 的 4×4 上三角），A − λI 是嚴格上三角，只要上面有非零元素，rank 就 ≥ 1，幾何重數常常只剩 1。

不能對角化的典型矩陣

  • Jordan 區塊 [λ 1; 0 λ]：特徵值 λ 二重，A − λI = [0 1; 0 0] 的 rank 是 1，g = 1 < 2。
  • 非零的冪零矩陣（Nm = 0 但 N ≠ 0）：特徵值全是 0；若可對角化則 N = P·0·P−1 = 0，矛盾。
  • 這類矩陣退而求其次的「最接近對角」的形式是 Jordan Canonical Form Jordan 標準式（籌備中）。

反過來，有些矩陣「一定」可以對角化：n 個相異特徵值；實對稱矩陣（而且 P 可以選成正交矩陣，這是 Symmetric and Hermitian Matrices 對稱矩陣與譜定理（籌備中）的主題）；滿足 A2 = A 的冪等矩陣（特徵值只有 0、1，且 Null(A) 和 Col(A) 合起來就是 ℝn）。

對角化的步驟：組出 P 與 D

把上面的判準和特徵向量的求法串起來，就是對角化的完整流程：

  1. 求特徵值：解 det(A − λI) = 0，記下代數重數（用 trace、det 驗算）。
  2. 每個特徵值求特徵空間：把 A − λI 化成 RREF，自由變數個數 = 幾何重數；每個自由變數輪流設 1 得到一個基底向量。
  3. 判斷：有任何 g(λ) < a(λ) 就停，A 不可對角化。
  4. 組 P、D：把所有基底向量依序排成 P 的行，D 的對角線在同樣的位置放對應的特徵值（重根就重複寫）。
  5. 驗算 AP = PD（逐行 Av = λv）；需要 P−1 時用 [P | I] 化簡（見 用 [A | I] 求反矩陣）。

例子：A = [2 1 −1; −1 4 −1; −2 2 1]。

步驟計算結果
1. 特徵值det(A − λI) = −λ3 + 7λ2 − 15λ + 9 = −(λ − 1)(λ − 3)2λ = 1（a = 1）、λ = 3（a = 2）；驗算 1 + 3 + 3 = 7 = tr A，1·3·3 = 9 = det A
2. λ = 1A − I = [1 1 −1; −1 3 −1; −2 2 0] → RREF [1 0 −1/2; 0 1 −1/2; 0 0 0]x3 自由，取 x3 = 2：v1 = (1, 1, 2)
2. λ = 3A − 3I → RREF [1 −1 1; 0 0 0; 0 0 0]，rank 1x2、x3 自由：v2 = (1, 1, 0)、v3 = (−1, 0, 1)
3. 判斷g(1) = 1 = a(1)，g(3) = 2 = a(3)可對角化
4. 組 P、DP = [v1 v2 v3] = [1 1 −1; 1 1 0; 2 0 1]D = diag(1, 3, 3)
5. 驗算Av1 = (1, 1, 2)、Av2 = (3, 3, 0)、Av3 = (−3, 0, 3)分別是 1·v1、3·v2、3·v3，AP = PD 成立

注意第 4 步 D 的對角線是 1、3、3：λ = 3 有兩個特徵向量，就要在 D 寫兩次 3，而且放在 v2、v3 所在的第 2、3 行。程式也照同樣的順序做：每找到一個特徵空間，就把它的基底一個一個塞進 P 的下一行，同時在 D 的同一個位置寫上特徵值；遇到幾何重數不夠就立刻回傳「不可對角化」。

看程式碼：diagonalize() / checkAPPD()：組出 P、D 並驗算
diagonalize()：每個特徵空間的基底依序排成 P 的行
int diagonalize(Frac A[MAXN][MAXN], Frac P[MAXN][MAXN], Frac D[MAXN][MAXN]) {   /* 可對角化回傳 1、缺陷回傳 0 */
  Frac lam[MAXN], basis[MAXN][MAXN];
  int alg[MAXN], col = 0;
  Poly rest;
  int k = eigenvalues(charPoly(A), lam, alg, &rest);
  if (rest.deg > 0) return -1;                 /* 有無理根或複數根：P、D 不是有理數，這裡不處理 */
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) D[i][j] = frac(0, 1);
  for (int t = 0; t < k; t++) {
    int g = eigenspace(A, lam[t], basis);      /* g = 幾何重數 = n − rank(A − λI) */
    if (g < alg[t]) return 0;                  /* 幾何重數 < 代數重數：特徵向量不夠 n 個 */
    for (int s = 0; s < g; s++, col++) {
      for (int i = 0; i < n; i++) P[i][col] = basis[s][i];   /* 第 col 個特徵向量放進 P 的第 col 行 */
      D[col][col] = lam[t];                    /* 對應的特徵值放在 D 的同一行 */
    }
  }
  return 1;                                    /* 此時 col == n，P 的 n 行線性獨立 */
}
checkAPPD()：驗算 AP = PD
int checkAPPD(Frac A[MAXN][MAXN], Frac P[MAXN][MAXN], Frac D[MAXN][MAXN]) {   /* 驗算 AP = PD */
  Frac L[MAXN][MAXN], R[MAXN][MAXN];
  matMul(A, P, L);                             /* AP 的第 j 行 = A·(P 的第 j 行) */
  matMul(P, D, R);                             /* PD 的第 j 行 = d_jj·(P 的第 j 行) */
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
      if (!feq(L[i][j], R[i][j])) return 0;
  return 1;
}
inverse()：[P | I] → [I | P⁻¹]
int inverse(Frac P[MAXN][MAXN], Frac inv[MAXN][MAXN]) {   /* 不可逆回傳 0 */
  Frac M[MAXN][2 * MAXN];
  for (int i = 0; i < n; i++)
    for (int j = 0; j < 2 * n; j++) M[i][j] = (j < n) ? P[i][j] : frac(j - n == i, 1);
  for (int c = 0; c < n; c++) {
    int p = c;
    while (p < n && isZero(M[p][c])) p++;
    if (p == n) return 0;                      /* 這一行找不到 pivot：P 不可逆 */
    for (int j = 0; j < 2 * n; j++) { Frac t = M[c][j]; M[c][j] = M[p][j]; M[p][j] = t; }
    Frac piv = M[c][c];
    for (int j = 0; j < 2 * n; j++) M[c][j] = fdiv(M[c][j], piv);
    for (int i = 0; i < n; i++)
      if (i != c && !isZero(M[i][c])) {
        Frac f = M[i][c];
        for (int j = 0; j < 2 * n; j++) M[i][j] = fsub(M[i][j], fmul(f, M[c][j]));
      }
  }
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) inv[i][j] = M[i][n + j];
  return 1;
}

程式裡的 eigenvalues()（有理根定理求特徵值）和 eigenspace()（RREF 讀出特徵空間基底）就是 求特徵向量 那一頁的版本。下面的動畫把整個流程串起來：輸入 2×2 或 3×3 矩陣（可以用分數），它會求特徵值、逐一算 rank(A − λI) 與幾何重數、判斷能不能對角化，把特徵向量排進 P、特徵值排進 D，逐行驗算 AP = PD；按「算 Aᵏ」還會求 P−1、Dk，算出 Ak = P Dk P−1，並和直接連乘的結果比對、說明 k → ∞ 時的趨勢。遇到無理數或複數特徵值（例如 Fibonacci 矩陣）時會說明能不能對角化，並直接用快速冪算 Ak。

用對角化算 Aᵏ 與矩陣多項式

Ak = P Dk P−1

A2 = (PDP−1)(PDP−1) = PD(P−1P)DP−1 = PD2P−1，中間的 P−1P = I 消掉了。重複 k 次：

A^k = P D^k P⁻¹ = P · diag(λ₁^k, λ₂^k, …, λₙ^k) · P⁻¹

對角矩陣的次方只要把每個對角元素各自 k 次方，所以不管 k 多大，都是「兩次矩陣乘法」。順序一定是 P 在左、P−1 在右（P 的行是特徵向量）；寫成 P−1DkP 是最常見的錯誤，代 k = 1 檢查是否得到 A 就能抓到。

例子：A = [4 1; 2 3]，P = [−1 1; 2 1]、D = diag(2, 5)、P−1 = (1/3)[−1 1; 2 1]：

A^k = (1/3) [ 2^k + 2·5^k      −2^k + 5^k   ]
            [ −2·2^k + 2·5^k   2·2^k + 5^k  ]

檢查 k = 1：(1/3)[2 + 10, −2 + 5; −4 + 10, 4 + 5] = [4 1; 2 3]。代 k = 5 得 A5 = [2094 1031; 2062 1063]，和直接連乘 5 次相同（已用程式驗證）。k 很大時 5k 遠大於 2k，Ak ≈ (5k/3)[2 1; 2 1]：最大的特徵值主導長期行為。

另一種寫法：拆成特徵向量的組合

圖 3 也可以直接寫成 Akx = c1λ1kv1 + ⋯ + cnλnkvn，其中 c = P−1x。只問 Akx（不用整個 Ak）時，解一次 Pc = x 比求 P−1 快。把矩陣本身拆開也行：Ak = λ1kE1 + ⋯，其中 Ei = (P 的第 i 行)(P−1 的第 i 列) 是只和 A 有關的固定矩陣；2×2、特徵值 λ1 ≠ λ2 時 E1 = (A − λ2I)/(λ1 − λ2)，不用求 P 就能寫出 Ak。

k → ∞：看特徵值的絕對值

特徵值λk 的行為Ak 的極限
全部 |λ| < 1都 → 0Ak → 0
λ = 1，其餘 |λ| < 11k = 1 留下，其餘 → 0收斂到 P·diag(1, 0, …, 0)·P−1，也就是投影到 E1 的矩陣
有 λ = −1（或其他 |λ| = 1 且 λ ≠ 1）(−1)k 正負交替不收斂（震盪）
有 |λ| > 1→ ∞發散（除非初始向量在那個方向的座標剛好是 0）

第二種情況就是 Markov Chains 馬可夫鏈與非負矩陣（籌備中）的穩定狀態：例如 A = [1/2 1/4; 1/2 3/4] 每行和為 1，特徵值 1、1/4，特徵向量 (1, 2)、(−1, 1)；lim Ak = [1/3 1/3; 2/3 2/3]，不管從哪個機率分布出發，最後都收斂到 (1/3, 2/3)。動畫的「分數（收斂）」按鈕就是這個矩陣。

矩陣多項式與矩陣函數：f(A) = P f(D) P−1

多項式 p(A) = amAm + ⋯ + a1A + a0I 的每一項都可以寫成 P(⋯)P−1，所以 p(A) = P·diag(p(λ1), …, p(λn))·P−1。推論：p(A) 的特徵值是 p(λi)，det p(A) = Π p(λi)；而且若 p(λi) 全是 0（例如 p 是特徵多項式），p(A) = 0，這是可對角化情況下 Cayley–Hamilton 定理的一行證明（一般情況見 Cayley–Hamilton 定理）。

同樣的想法可以定義非多項式的函數：

  • eA = Σ Ak/k! = P·diag(eλ1, …, eλn)·P−1，是解 x′ = Ax 的工具（Systems of Linear Differential Equations 線性微分方程組（籌備中））。若 A 的特徵值只有 0、1（冪等矩陣 A2 = A），eA = I + (e − 1)A。
  • 平方根、立方根：要找 B 使 B2 = A，取 B = P·diag(√λ1, …)·P−1。每個特徵值的根號可以取正或負，所以 2×2 相異正特徵值就有 4 個平方根；題目通常會加條件（例如「B 的特徵值為正」或「為實數」）讓答案唯一。

例：A = [−2 3; −6 7]，特徵值 1、4，特徵向量 (1, 1)、(1, 2)。取 P = [1 1; 1 2]、P−1 = [2 −1; −1 1]，B = P·diag(1, 2)·P−1 = [0 1; −2 3]，直接驗算 B2 = [−2 3; −6 7]。

看程式碼：powerByDiag() / matPow()：Aᵏ 的兩種算法
powerByDiag()：A^k = P D^k P⁻¹
void powerByDiag(Frac P[MAXN][MAXN], Frac D[MAXN][MAXN], int k, Frac Ak[MAXN][MAXN]) {
  Frac Dk[MAXN][MAXN], Pinv[MAXN][MAXN], T[MAXN][MAXN];
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) Dk[i][j] = (i == j) ? fpow(D[i][i], k) : frac(0, 1);   /* D^k = diag(λ₁^k, …, λₙ^k) */
  inverse(P, Pinv);
  matMul(P, Dk, T);                            /* T = P D^k */
  matMul(T, Pinv, Ak);                         /* A^k = P D^k P⁻¹ */
}
matPow()：快速冪直接算 A^k（對答案用）
void matPow(Frac A[MAXN][MAXN], int k, Frac R[MAXN][MAXN]) {   /* 直接算 A^k（快速冪），用來對答案 */
  Frac B[MAXN][MAXN];
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) { R[i][j] = frac(i == j, 1); B[i][j] = A[i][j]; }
  while (k > 0) {
    if (k & 1) matMul(R, B, R);                /* 二進位這一位是 1：乘進答案 */
    matMul(B, B, B);                           /* B ← B²，只要 O(log k) 次矩陣乘法 */
    k >>= 1;
  }
}
fpow()：分數的 k 次方
Frac fpow(Frac x, int k) {                     /* x^k，k ≥ 0 */
  Frac r = frac(1, 1);
  for (int t = 0; t < k; t++) r = fmul(r, x);
  return r;
}

效能上的比較：直接連乘要 k − 1 次矩陣乘法（n×n 每次 n3 次乘法）；快速冪只要約 2 log2k 次；對角化之後是固定的 2 次矩陣乘法加 n 個純量次方，還多了一個封閉式，可以拿來分析趨勢、求極限、做 mod 運算。考試要的通常是封閉式，程式要的通常是快速冪（不怕特徵值是無理數）。

遞迴式：Fibonacci 與線性遞迴

二階線性遞迴 ak+2 = p·ak+1 + q·ak 每一步只依賴前兩項，把相鄰兩項打包成狀態向量 uk = (ak+1, ak)，就變成一階的矩陣遞迴：

[a_{k+2}]   [p  q] [a_{k+1}]
[a_{k+1}] = [1  0] [a_k    ]       即 u_{k+1} = A u_k，所以 u_k = A^k u_0

A 的特徵多項式是 λ2 − pλ − q，正好是遞迴式的特徵方程式。所以 離散數學的特徵根解法 和這裡的對角化是同一件事：特徵根相異時 ak = αr1k + βr2k，對應 A 有兩個相異特徵值、可對角化；特徵根重根時通解要多一個 k·rk，對應這個 A 只有一個特徵向量（[p q; 1 0] − rI 的第 2 列 (1, −r) 永遠非零，rank 1），不能對角化。

例 1：特徵根是整數

ak+2 = ak+1 + 2ak，a0 = 0、a1 = 1。A = [1 2; 1 0]，特徵方程式 λ2 − λ − 2 = (λ − 2)(λ + 1)，特徵值 2、−1。對 [p q; 1 0] 這種矩陣，λ 的特徵向量一定可以取 (λ, 1)（第 2 列說 x1 = λx2），所以 P = [2 −1; 1 1]。

u0 = (a1, a0) = (1, 0) = c1(2, 1) + c2(−1, 1)，解得 c1 = 1/3、c2 = −1/3。uk = (1/3)2k(2, 1) − (1/3)(−1)k(−1, 1)，取第 2 個分量：

a_k = (2^k − (−1)^k) / 3        a_10 = (1024 − 1)/3 = 341

程式對 k = 0～30 都用矩陣快速冪檢查過這個封閉式；動畫的「遞迴」按鈕會算出 A10 = [683 682; 341 342]，第 2 列第 1 行的 341 就是 a10（Ak 的第 2 列第 1 行 = ak，因為 u0 = (1, 0) 只取出 Ak 的第 1 行）。

例 2：Fibonacci

Fk+2 = Fk+1 + Fk，A = [1 1; 1 0]，特徵方程式 λ2 − λ − 1 = 0，特徵值 φ = (1 + √5)/2 ≈ 1.618、ψ = (1 − √5)/2 ≈ −0.618。兩根相異，所以 A 可對角化（P、D 含 √5）。同樣的推導得到 Binet's Formula（比內公式）：

F_k = (φ^k − ψ^k) / √5          A^k = [F_{k+1}  F_k    ]
                                        [F_k      F_{k−1}]

|ψ| < 1，所以 ψk → 0，Fk 是最接近 φk/√5 的整數，Fk+1/Fk → φ（黃金比例）。這就是「最大特徵值主導長期行為」的例子。Ak 的右邊那個等式（可以用歸納法證明）也給了 O(log k) 求 Fk 的方法：用快速冪算 [1 1; 1 0]k，只要整數運算、不會有 √5 的誤差；F40 = 102334155 就是這樣算出來核對的。

看程式碼：recurByMatrix()：用 A^k 求線性遞迴的第 k 項
recurByMatrix()：a_{k+2} = p·a_{k+1} + q·a_k
long long recurByMatrix(long long p, long long q, long long a0, long long a1, int k) {   /* 回傳 a_k */
  Frac A[MAXN][MAXN], R[MAXN][MAXN];
  n = 2;
  A[0][0] = frac(p, 1); A[0][1] = frac(q, 1);  /* [a_{k+2}; a_{k+1}] = [p q; 1 0][a_{k+1}; a_k] */
  A[1][0] = frac(1, 1); A[1][1] = frac(0, 1);
  matPow(A, k, R);                             /* [a_{k+1}; a_k] = A^k [a_1; a_0] */
  return fadd(fmul(R[1][0], frac(a1, 1)), fmul(R[1][1], frac(a0, 1))).n;
}

同樣的手法可以推廣：三階遞迴用 3×3 的狀態矩陣；兩個互相影響的序列（例如 xk+1 = 2xk + yk、yk+1 = xk + 2yk）直接寫成 uk+1 = Auk。演算法裡用矩陣快速冪做 DP 加速（例如計算長度為 k 的路徑數 = 鄰接矩陣的 k 次方）也是同一個想法。

相似矩陣的性質

定義：若存在可逆矩陣 P 使 B = P−1AP，就說 A 和 B Similar（相似），記作 A ~ B。所以「A 可對角化」就是「A 和某個對角矩陣相似」。

相似的意思是：A 和 B 是同一個線性轉換在兩組不同基底下的矩陣，P 的行就是新基底在舊座標下的寫法（完整的線性轉換觀點見 Similarity 相似矩陣（籌備中）與 Change of Basis 基底變換（籌備中））。既然是同一個轉換，和「座標怎麼選」無關的量都應該一樣：

相似矩陣相同的量理由（B = P−1AP）
特徵多項式、特徵值（含代數重數）det(B − λI) = det(P−1(A − λI)P) = det(P−1)det(A − λI)det(P) = det(A − λI)
det、trace分別是特徵值的積與和；也可直接用 det(XY) = det X det Y、tr(XY) = tr(YX)
rank、nullity乘上可逆矩陣不改變 rank
每個特徵值的幾何重數B − λI = P−1(A − λI)P，rank 相同，所以 dim Eλ 相同
可不可逆、可不可對角化A = QDQ−1 ⇒ B = (P−1Q)D(P−1Q)−1
Bk ~ Ak，p(B) ~ p(A)Bk = P−1AkP

會改變的：特徵向量。若 Av = λv，則 B(P−1v) = P−1AP·P−1v = λ(P−1v)，B 的特徵向量是 P−1v，一般和 v 不同。對稱性、元素本身、列空間、行空間也都會變。

反過來不成立：特徵值相同 ≠ 相似

[1 1; 0 1] 和 I 的特徵多項式都是 (λ − 1)2，trace、det 都相同，但不相似：和 I 相似的矩陣只有 P−1IP = I 自己。用表格的不變量也看得出來：rank(A − I) 分別是 1 和 0，幾何重數不同。上面「判準」一節的兩個 3×3 矩陣也是同一個例子：特徵多項式相同，一個可對角化、一個不行，所以不相似。

但在可對角化的前提下就成立：若 A、B 都可對角化而且特徵值（含重數）相同，則 A ~ D ~ B，相似有遞移性，所以 A ~ B。實用版本：兩個 n×n 矩陣都有同樣的 n 個相異特徵值 ⇒ 相似。例如 [1 2; 0 3] 和 [1 0; 2 3] 的特徵值都是 1、3，相異，所以相似。

常考的連帶結論

  • A 可對角化 ⇒ AT 可對角化：A = PDP−1 取轉置得 AT = (PT)−1DPT，令 Q = (PT)−1 即可。
  • A 可對角化 ⇒ Ak、p(A) 可對角化（同一個 P）；A 可逆時 A−1 = PD−1P−1 也可對角化。反之不一定：A2 可對角化不代表 A 可以（[0 1; 0 0]2 = 0）。
  • A 可對角化 與 A 可逆沒有關係：零矩陣可對角化但不可逆；[1 1; 0 1] 可逆但不可對角化。
  • 兩個可對角化的矩陣若能用同一個 P 對角化（simultaneously diagonalizable），則 AB = PD1D2P−1 = BA，兩者可交換。

易錯點

  • 可對角化一定要有 n 個相異特徵值 → 相異是充分條件、不是必要條件；In 只有一個特徵值卻本身就是對角矩陣，看的是每個 λ 的幾何重數是否等於代數重數 例題
  • 有重根就不能對角化 → 重根只是「需要檢查」：rank(A − λI) = n − a(λ) 就沒問題，例如 λ = 3 二重而 A − 3I 三列成比例 例題
  • 特徵值重數是多少，特徵空間就是幾維 → 幾何重數要另外算 n − rank(A − λI)，只保證 1 ≤ g ≤ a；對角線全相同的上三角矩陣常常只有 1 維 例題
  • 可對角化就可逆，或可逆就可對角化 → 兩者無關：0 可對角化但不可逆，[1 1; 0 1] 可逆但不可對角化；可逆看 0 是不是特徵值，可對角化看特徵向量夠不夠 例題
  • P 和 D 是唯一的，D 的順序隨便排 → P 可以乘倍數、換順序，重根時特徵空間的基底也能任選；但 P 第 j 行的特徵向量一定要配 D 第 j 個對角元素 例題
  • Ak = P−1DkP → P 的行是特徵向量時是 Ak = PDkP−1（P 在左）；寫完代 k = 1 看是否回到 A 例題
  • 特徵多項式（或 trace、det、rank）都相同就相似 → 還要比幾何重數；[1 1; 0 1] 和 I 特徵值相同但不相似。兩者都可對角化（例如都有 n 個相異特徵值）時才保證相似 例題
  • lim Ak 一定存在，把 λk 換成極限就好 → 有 |λ| > 1 就發散、有 λ = −1 就震盪；只有其餘 |λ| < 1、留下的 |λ| = 1 都是 λ = 1 時才收斂 例題
  • B3 = A、B2 = A 的解只有一個，直接把特徵值開根號 → 每個特徵值的根有多種取法（平方根 ±、複數立方根），要依題目條件（實數、正特徵值）挑；B 用和 A 同一個 P 例題 例題
