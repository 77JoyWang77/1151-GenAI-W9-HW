為什麼需要行列式

在 可逆的等價條件 裡，判斷一個方陣可不可逆要做一整輪消去，看 pivot 夠不夠。能不能只算一個數字就知道答案？這個數字就是 Determinant（行列式），記作 det A 或 |A|。

行列式同時回答三件事：

  • 可不可逆：det A ≠ 0 ⇔ A 可逆 ⇔ Ax = 0 只有零解。考題裡「齊次方程組何時有非零解」「哪個參數讓矩陣奇異」都是在解 det = 0。
  • 體積縮放倍率：|det A| 是 A 把單位正方形（正方體）變形後的面積（體積）。det A = 0 表示空間被壓扁到更低的維度，所以資訊回不去，也就不可逆。
  • 方向：det A 的正負號代表有沒有「翻面」（鏡射）。正交矩陣的 det 只能是 ±1，+1 是旋轉、−1 含鏡射。

考研對這一章的要求很明確：大矩陣要能快速算出 det（挑零多的列展開、先做列運算），一長串性質要分得清哪些對、哪些是陷阱（det(cA)、det(A + B)、列等價），以及看到特殊結構能直接寫出答案（三角、區塊、Vandermonde、全 1 矩陣）。用行列式解方程組的 Cramer 法則和伴隨矩陣放在 Cramer's Rule and Adjugate Cramer 法則與伴隨矩陣（籌備中）。

定義：從 2×2 到排列展開

2×2 與幾何意義

det [ a  b ] = ad − bc
    [ c  d ]

把 A 的兩個行向量 (a, c)、(b, d) 當成平行四邊形的兩邊，ad − bc 的絕對值就是它的面積。例如 A = [3 1; 1 2]，兩行是 (3, 1) 和 (1, 2)，det A = 3·2 − 1·1 = 5，代表單位正方形被 A 變成面積 5 的平行四邊形。

3×3 與 Sarrus 法則

3×3 可以用 Sarrus Rule（對角線法則）：右下方向三條對角線的乘積相加，減去左下方向三條。以 A = [2 −1 3; 1 0 4; −2 5 1] 為例：

正項：2·0·1 + (−1)·4·(−2) + 3·1·5 = 0 + 8 + 15 = 23
負項：3·0·(−2) + 2·4·5 + (−1)·1·1 = 0 + 40 − 1 = 39
det A = 23 − 39 = −16

Sarrus 法則只適用 3×3。4×4 照抄「對角線」只會得到 8 項，但真正的展開有 4! = 24 項，答案一定錯。

一般定義：排列展開

n×n 的行列式定義成 n! 項的和，每一項是「每一列選一個元素、而且各在不同行」的乘積：

det A = Σ  sgn(σ) · a_{1σ(1)} · a_{2σ(2)} ⋯ a_{nσ(n)}
        σ
σ 走遍 1..n 的所有排列（共 n! 個）；sgn(σ) = (−1)^(σ 的逆序數)

Inversion（逆序）是排列中前面比後面大的數對。例如 σ = (2, 1, 3) 只有 (2, 1) 一個逆序，sgn = −1，所以 a12a21a33 這一項帶負號。2×2 的 ad − bc 就是 σ = (1, 2)（0 個逆序，+）和 σ = (2, 1)（1 個逆序，−）兩項。

這個定義平常不拿來算數字（10×10 有 3,628,800 項），但有三個用途：(1) 證明性質（例如 det AT = det A）；(2) 數「非零項有幾個」：每列選一個非零元素、各在不同行的選法數；(3) 問某個 x 次方的係數時，只要找出含那麼多個 x 的排列。程式窮舉驗證：4×4 全非零時恰好 24 項，4×4 三對角矩陣只有 5 個非零項。

看程式碼：countNonzeroTerms()：數排列展開的非零項
enumerate() / countNonzeroTerms()：每列選一個非零、各在不同行
int perm[MAXN], used[MAXN];
long long termCount;

void enumerate(const int *pattern, int size, int row) {   /* pattern[i*size+j] != 0 表示該位置非零 */
  if (row == size) { termCount++; return; }
  for (int c = 0; c < size; c++) {
    if (used[c] || !pattern[row * size + c]) continue;   /* 每列選一個非零、各在不同行 */
    used[c] = 1; perm[row] = c;
    enumerate(pattern, size, row + 1);
    used[c] = 0;
  }
}

long long countNonzeroTerms(const int *pattern, int size) {
  termCount = 0;
  memset(used, 0, sizeof used);
  enumerate(pattern, size, 0);
  return termCount;
}
inversions()：決定每一項的正負號
int inversions(const int *p, int size) {        /* 逆序數：奇數 → 該項取負號 */
  int inv = 0;
  for (int i = 0; i < size; i++)
    for (int j = i + 1; j < size; j++)
      if (p[i] > p[j]) inv++;
  return inv;
}

餘因子展開

把排列展開依「第 i 列選了哪一行」分組，就得到 Cofactor Expansion（餘因子展開，又稱 Laplace 展開），把 n 階拆成 n 個 n − 1 階：

  • Minor（子行列式） Mij：刪掉第 i 列、第 j 行剩下的 (n − 1) 階行列式。
  • Cofactor（餘因子） Cij = (−1)i+j Mij。符號是棋盤格：左上角 +，往右往下交錯。
沿第 i 列：det A = a_i1·C_i1 + a_i2·C_i2 + ⋯ + a_in·C_in
沿第 j 行：det A = a_1j·C_1j + a_2j·C_2j + ⋯ + a_nj·C_nj

沿任何一列或一行展開，答案都一樣，所以要挑 0 最多的那一列（行）：aij = 0 的那一項整個不用算。用上一節的 A = [2 −1 3; 1 0 4; −2 5 1]，第 2 列 (1, 0, 4) 有一個 0：

C21 = (−1)^(2+1) · det[−1 3; 5 1] = −(−1 − 15) = 16
C23 = (−1)^(2+3) · det[ 2 −1; −2 5] = −(10 − 2) = −8
det A = 1·16 + 0·C22 + 4·(−8) = 16 − 32 = −16

和 Sarrus 的結果一樣（程式沿每一列都展開過一次，三列都得 −16）。

考題常見的 5×5、6×6 數字矩陣（例如某一行只有一個非零）就是這樣一層一層剝：每次挑只剩一兩個非零的列或行，注意每一層的符號 (−1)i+j 是用「當下這個子矩陣」的列號、行號算，不是原矩陣的位置。

看程式碼：detCofactor()：餘因子展開（遞迴）
minorOf() / detCofactor()：沿第 1 列展開
void minorOf(Frac A[MAXN][MAXN], int size, int r, int c, Frac M[MAXN][MAXN]) {
  for (int i = 0, mi = 0; i < size; i++) {     /* 刪掉第 r 列、第 c 行 */
    if (i == r) continue;
    for (int j = 0, mj = 0; j < size; j++) {
      if (j == c) continue;
      M[mi][mj++] = A[i][j];
    }
    mi++;
  }
}

Frac detCofactor(Frac A[MAXN][MAXN], int size) {     /* 沿第 1 列餘因子展開（遞迴） */
  if (size == 1) return A[0][0];
  Frac d = frac(0, 1);
  for (int c = 0; c < size; c++) {
    if (isZero(A[0][c])) continue;               /* 0 的那一項不用算 */
    Frac M[MAXN][MAXN];
    minorOf(A, size, 0, c, M);                   /* 刪掉第 1 列、第 c+1 行 */
    Frac term = fmul(A[0][c], detCofactor(M, size - 1));
    d = (c % 2 == 0) ? fadd(d, term) : fsub(d, term);   /* 符號 (−1)^(1+j) */
  }
  return d;
}
expandAlongRow()：沿第 r+1 列展開，用來驗證每一列結果相同
Frac expandAlongRow(Frac A[MAXN][MAXN], int size, int r) {   /* 沿第 r+1 列展開 */
  Frac d = frac(0, 1);
  for (int c = 0; c < size; c++) {
    if (isZero(A[r][c])) continue;
    Frac M[MAXN][MAXN];
    minorOf(A, size, r, c, M);
    Frac cof = detCofactor(M, size - 1);         /* 子行列式 M_rc */
    if ((r + c) % 2 == 1) cof = fmul(cof, frac(-1, 1));   /* 餘因子 C_rc = (−1)^(r+c) M_rc */
    d = fadd(d, fmul(A[r][c], cof));
  }
  return d;
}

列運算對行列式的影響

餘因子展開對沒有 0 的矩陣很慢。真正好用的是：先用列運算製造 0 或化成上三角。三種基本列運算（見 增廣矩陣與三種列運算）對 det 的影響各不相同：

列運算det 變成為什麼
Ri ↔ Rj（交換）−det A排列展開中每一項的逆序數奇偶都改變；推論：兩列相同時 det A = −det A，所以 det = 0
Ri ← cRi（倍乘，c ≠ 0）c · det A每一項剛好含第 i 列的一個元素，可以提出 c
Ri ← Ri + cRj（加倍數）det A（不變）拆成 det A + c·det(第 i 列換成 Rj 的矩陣)，後者有兩列相同，等於 0

用基本矩陣的語言：三型基本矩陣的 det 分別是 −1、c、1（見 基本矩陣），上表就是 det(EA) = det(E)·det(A)。行運算的效果完全一樣，因為 det AT = det A（下一節），所以手算時列、行運算可以混用。

化成上三角求 det

上三角矩陣沿第一行一路展開，只剩對角線乘積。所以只用「交換」和「加倍數」把 A 化成上三角 U，就有

det A = (−1)^(交換次數) × (U 的對角線乘積)

例：A = [0 2 1 3; 1 1 0 2; 2 4 1 5; 1 3 2 2]（下方動畫的預設例子）：

步驟列運算det 的影響結果
1R1 ↔ R2（a11 = 0 不能當 pivot）× (−1)R1 = (1, 1, 0, 2)
2R3 − 2R1、R4 − R1不變R3 = (0, 2, 1, 1)、R4 = (0, 2, 2, 0)
3R3 − R2、R4 − R2不變R3 = (0, 0, 0, −2)、R4 = (0, 0, 1, −3)
4R3 ↔ R4（第 3 行 pivot 是 0）× (−1)對角線 1, 2, 1, −2

交換了 2 次，正負號 (−1)2 = +1，det A = 1 × 2 × 1 × (−2) = −4（程式用餘因子展開、兩種 pivot 規則的消去都得到 −4）。

如果中途為了好算做了倍乘（例如把一列除以 3），要記得最後乘回 3；方向搞反（除錯成乘）是最常見的失分。最穩的做法是：除了交換以外，只用「加倍數」。

看程式碼：detElim()：化成上三角求 det
detElim()：只用交換與加倍數，det = 正負號 × 對角線乘積
void swapRows(Frac U[MAXN][MAXN], int size, int a, int b) {
  for (int j = 0; j < size; j++) { Frac t = U[a][j]; U[a][j] = U[b][j]; U[b][j] = t; }
}

Frac detElim(Frac A[MAXN][MAXN], int size, int pickMax) {   /* 化成上三角，det = 正負號 × 對角線乘積 */
  Frac U[MAXN][MAXN];
  copyMat(A, U, size);
  int sign = 1;                                  /* 每交換一次列就變號 */
  for (int c = 0; c < size; c++) {
    int p = c;                                   /* 在第 c 行、第 c 列以下找 pivot */
    for (int i = c; i < size; i++) {
      if (isZero(U[p][c]) && !isZero(U[i][c])) p = i;    /* 預設：第一個非零 */
      if (pickMax && absGreater(U[i][c], U[p][c])) p = i;   /* 選項：絕對值最大 */
    }
    if (isZero(U[p][c])) return frac(0, 1);      /* 這一行往下全是 0：det = 0 */
    if (p != c) { swapRows(U, size, p, c); sign = -sign; }   /* 列交換：det 變號 */
    for (int i = c + 1; i < size; i++) {         /* 列加上倍數：det 不變 */
      if (isZero(U[i][c])) continue;
      Frac f = fdiv(U[i][c], U[c][c]);
      for (int j = c; j < size; j++) U[i][j] = fsub(U[i][j], fmul(f, U[c][j]));
    }
  }
  Frac d = frac(sign, 1);
  for (int i = 0; i < size; i++) d = fmul(d, U[i][i]);   /* 上三角：det = 對角線乘積 */
  return d;
}
opSwap() / opScale() / opAdd()：追蹤 det(新) = factor × det(原)
/* 對 A 做一次列運算；factor 記錄 det(新矩陣) = factor × det(原矩陣) */
void opSwap(Frac A[MAXN][MAXN], int size, int i, int j, Frac *factor) {
  swapRows(A, size, i, j);                       /* R_i ↔ R_j：det 乘 −1 */
  *factor = fmul(*factor, frac(-1, 1));
}
void opScale(Frac A[MAXN][MAXN], int size, int i, Frac c, Frac *factor) {
  for (int k = 0; k < size; k++) A[i][k] = fmul(c, A[i][k]);   /* R_i ← cR_i：det 乘 c */
  *factor = fmul(*factor, c);
}
void opAdd(Frac A[MAXN][MAXN], int size, int i, int j, Frac c, Frac *factor) {
  for (int k = 0; k < size; k++) A[i][k] = fadd(A[i][k], fmul(c, A[j][k]));   /* R_i ← R_i + cR_j：det 不變 */
  (void)factor;
}
Frac：分子分母都是整數，隨時約分
typedef struct { long long n, d; } Frac;

long long gcdll(long long a, long long b) {
  if (a < 0) a = -a;
  if (b < 0) b = -b;
  while (b) { long long t = a % b; a = b; b = t; }
  return a ? a : 1;
}

Frac frac(long long n, long long d) {          /* 建立分數並約分 */
  if (d < 0) { n = -n; d = -d; }
  long long g = gcdll(n, d);
  Frac f = { n / g, d / g };
  return f;
}
Frac fadd(Frac x, Frac y) { return frac(x.n * y.d + y.n * x.d, x.d * y.d); }
Frac fsub(Frac x, Frac y) { return frac(x.n * y.d - y.n * x.d, x.d * y.d); }
Frac fmul(Frac x, Frac y) { return frac(x.n * y.n, x.d * y.d); }
Frac fdiv(Frac x, Frac y) { return frac(x.n * y.d, x.d * y.n); }   /* 呼叫前要確定 y 不是 0 */
int isZero(Frac x) { return x.n == 0; }
int absGreater(Frac x, Frac y) {               /* |x| > |y| ? */
  long long a = x.n < 0 ? -x.n : x.n, b = y.n < 0 ? -y.n : y.n;
  return a * y.d > b * x.d;
}

下面的動畫有兩種用法：(1) 按「化上三角求 det」跑 detElim()，右邊追蹤目前的正負號和每一步的影響，可以切換 pivot 規則（手算用「第一個非零」，數值計算用「絕對值最大」，交換次數不同但答案一樣）；(2) 在第二個輸入框寫自己的列運算，按「做列運算」看 det 每一步乘上多少。

常考性質

A、B 是 n×n，c 是純量。是非題幾乎都從這張表出：

性質為什麼 / 注意
det AT = det A排列 σ 和它的反排列逆序數相同；所以對列成立的性質，對行也成立
det(AB) = det A · det BA 不可逆時兩邊都是 0；A 可逆時寫成基本矩陣乘積，一個一個用 det(EB) = det E·det B
det(A−1) = 1 / det Adet A · det A−1 = det I = 1
det(Ak) = (det A)kdet(AB) 重複用
det(cA) = cn det A每一列都乘 c，提出 n 次；不是 c·det A
det(A + B) ≠ det A + det B（一般）行列式不是線性函數；反例 A = B = I（2×2）：det(2I) = 4，但 1 + 1 = 2
只差一列時可以相加A、B 只有第 i 列不同，C 的第 i 列 = 兩者之和、其餘相同 ⇒ det C = det A + det B（Multilinear（多線性）：對每一列各自線性）
det(P−1AP) = det A相似矩陣 det 相同，所以線性變換的 det 和選哪組基底無關
Q 正交 ⇒ det Q = ±1QTQ = I 兩邊取 det：(det Q)2 = 1
det A = 特徵值乘積（含重數）代 λ = 0 進特徵多項式，見 特徵值的常考性質
列等價 ⇏ det 相等I 和 2I 列等價，det 是 1 和 2n；列等價只保證「是不是 0」一致

用數字感受一下（程式驗算）：P = [1 2 0; 3 1 1; 0 2 4]、Q = [2 0 1; 1 1 0; 3 2 1]，det P = −22、det Q = 1。det(PQ) = −22 = (−22)·1，符合乘法；但 det(P + Q) = −6，不是 −22 + 1 = −21；det(2P) = −176 = 23·(−22)，不是 2·(−22) = −44。

多線性怎麼用

把行列式看成「各列的函數」det(r1, r2, …, rn)，它對每一列各自是線性的，而且兩列相同就是 0。所以像 det[a + 2b; b; 3c − a] 這種題目，不用知道 a、b、c 是什麼：先把第 1 列的 2b 用「減去 2 倍第 2 列」消掉、第 3 列的 −a 用「加上第 1 列」消掉，剩下 det[a; b; 3c] = 3·det[a; b; c]。同樣的想法也能處理「把行向量換成別的線性組合」的題目：如果某一行 d = −a + 3b，那 det[d b c] = −det[a b c] + 3·det[b b c] = −det[a b c]。

一眼看出 det = 0

det A = 0 ⇔ A 不可逆 ⇔ 列（行）向量線性相依 ⇔ rank A < n ⇔ Ax = 0 有非零解。考試的數字矩陣如果亂得很、又不准用計算機，通常就藏著下面其中一種：

  • 有一列（行）全是 0，或兩列（行）相同、成比例。注意要每個位置都成比例，差一個數字就不是（例如 (3, 6, 9, 12) 不是 (1, 2, 3, 6) 的 3 倍）。
  • 某一列是其他列的線性組合：A = [1 2 3; 4 5 6; 5 7 9] 的 R3 = R1 + R2，det = 0。看不出來時，試試 R1 ± R2、R1 − 2R2 + R3 這類小係數組合。
  • 每一列加起來都是 0：取 x = (1, 1, …, 1) 就有 Ax = 0。
  • 奇數階反對稱矩陣（AT = −A，n 奇數）：det A = det AT = det(−A) = (−1)n det A = −det A，所以 det A = 0。
  • 乘積裡有一個奇異：det(PQ) = det P · det Q，只要 P 或 Q 的 det 是 0 就是 0，不用真的乘開。

含參數：齊次方程組何時有非零解

Ax = 0 有非零解 ⇔ det A = 0，把 det 展開成參數的多項式再解方程。例如 det [x 1 1; 1 x 1; 1 1 x] = x3 − 3x + 2 = (x − 1)2(x + 2)，所以 x = 1 或 x = −2 時不可逆（程式代 x = −3～3 逐一驗算）。這種「對角線是 x、其他相同」的矩陣也可以用下一節 aI + bJ 的公式直接寫出。

Aij = r|i−j| 這類「每列是上一列的倍數再修正」先做 Rk − rRk−1由下往上做，對角線以下會全部消成 0

幾個數字例子（都用程式驗算過）：

  • Vandermonde：x = (2, 3, 5) 時 det [1 2 4; 1 3 9; 1 5 25] = (3 − 2)(5 − 2)(5 − 3) = 1·3·2 = 6。只要 xi 兩兩相異就可逆，和 xi 是不是 0 無關。
  • J − I（對角 0、其他 1）：a = −1、b = 1，det = (n − 1)(−1)n−1；n = 5 時是 4·1 = 4。
  • 三對角 2、−1、−1：Dn = 2Dn−1 − Dn−2，D1 = 2、D2 = 3，所以 Dn = n + 1。這類遞迴先算 D1、D2、D3 猜規律，再用遞迴式驗證。

區塊公式只對區塊三角成立。一般的 [A B; C D] 沒有 det A·det D − det B·det C 這種公式；左下、右上兩塊都不是 0 時，要先用區塊列運算消掉一塊，或乾脆化成上三角。

運算量：為什麼不用定義硬算

沿第一列餘因子展開，n 階要算 n 個 (n − 1) 階，乘法次數 T(n) = n·(T(n − 1) + 1)，大約是 e·n!（考慮所有元素都非零的最差情況）。化上三角每一步要更新 (n − k)×(n − k) 個位置，總共約 n3/3。程式逐一計數：

n餘因子展開（乘法）化上三角（乘除）意義
39103×3 差不多，Sarrus 或展開都可以
44023從 4×4 開始，列運算就比較快
61,23675差了約 16 倍，所以 6×6 的考題一定有很多 0 讓你展開
106,235,300339差了約 1.8 萬倍；電腦算 det 一律用消去（LU 分解）

手算策略：某一列（行）只剩一兩個非零 → 展開；否則 → 先做列運算製造 0，再展開。兩者混用最快。考題裡的程式碼若是遞迴呼叫「刪掉第 0 列第 c 行」的子矩陣，它就是在做餘因子展開，算的是 det。

看程式碼：cofactorMults() / elimMults()：乘法次數
兩種算法的乘除法次數
long long cofactorMults(int size) {             /* T(n) = n·(T(n−1) + 1)，T(1) = 0 */
  if (size == 1) return 0;
  return size * (cofactorMults(size - 1) + 1);
}
long long elimMults(int size) {                 /* 第 k 步：n−k 列 × (1 次除法 + n−k 次乘法)，最後 n−1 次乘對角線 */
  long long cnt = 0;
  for (int k = 1; k < size; k++) cnt += (long long)(size - k) * (size - k + 1);
  return cnt + (size - 1);
}

易錯點

  • det(cA) = c·det A → 每一列都乘了 c，要提出 n 次：det(cA) = cn det A；det(−A) = (−1)n det A 例題
  • det(A + B) = det A + det B、det(A − B) = det A − det B → 行列式不是線性函數；只有「只差一列」時才能把那一列拆開相加 例題
  • 列等價的矩陣行列式相等 → 交換、倍乘都會改 det；列等價只保證 det 同為 0 或同不為 0（I 和 2I 是反例） 例題
  • 化簡時把一列除以 3，最後忘了補，或補成除以 3 → det(新) = factor × det(原)，要求原矩陣就除以 factor；交換一次就乘 −1 例題
  • 4×4 也能用 Sarrus 的對角線法則 → 對角線法則只適用 3×3；4×4 有 24 項，只畫對角線只有 8 項 例題
  • 餘因子展開的符號照原矩陣的位置算 → 每展開一層，(−1)i+j 都用當下子矩陣的列號、行號 例題
  • det [A B; C D] = det A·det D − det B·det C → 只有區塊三角才是 det A·det D；區塊反對角 [0 A; B 0] 要數換列次數決定正負號 例題
  • 兩列「幾乎」成比例就說 det = 0 → 每個位置都要成比例才行，差一個數字就可能不為 0 例題
  • det A 是相異特徵值的乘積 → 要照代數重數重複相乘 例題
