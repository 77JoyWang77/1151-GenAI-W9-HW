Gaussian Elimination 高斯消去法與列梯形用列運算把方程組化成階梯，看 pivot 就知道有幾組解

Ch1 Matrices and Systems of Equations 難度 REF RREF rank pivot

為什麼需要高斯消去法

線性代數一開始要解決的問題，就是解 System of Linear Equations（線性方程組）：好幾條一次方程式、好幾個未知數，要找出同時滿足所有方程式的解。兩個未知數的時候，國中學過的代入消去法就夠了；但未知數一多，隨意代入很容易算亂，也很難判斷到底有沒有解、有幾組解。

從幾何來看，兩個未知數的每條方程式是平面上的一條直線，解就是直線的交點。兩條直線只有三種關係：相交於一點（唯一解）、平行（無解）、重合（無限多解）。三個未知數時每條方程式是空間中的一個平面，情況一樣只有這三種。不可能剛好有 2 組解：只要有兩組不同的解，連線上的每一點都是解。

Gaussian Elimination（高斯消去法）就是把代入消去法變成一套固定步驟：不管有幾條方程式、幾個未知數，都照同樣的規則一行一行消下去，最後一定能看出是哪一種情況，並把解寫出來。它也是之後求反矩陣、算秩、找基底、求特徵向量的共同工具，幾乎每一章都會用到。

增廣矩陣與三種列運算

解方程組時，真正在變的只有係數，未知數的名字只是佔位置。所以把每條方程式的係數寫成一列，等號右邊的常數放在最後一行，就得到 Augmented Matrix（增廣矩陣） [A | b]。例如：

 x +  y +  z = 6          [ 1   1   1 |  6 ]
2x −  y +  z = 3    →     [ 2  −1   1 |  3 ]
 x + 2y −  z = 2          [ 1   2  −1 |  2 ]

對方程式做下面三種動作，解完全不會改變，對應到矩陣就是三種 Elementary Row Operations（基本列運算）：

列運算寫法對方程式來說為什麼解不變
列交換Ri ↔ Rj兩條方程式換順序方程式的集合沒變
列乘以非零常數Ri ← cRi（c ≠ 0）整條方程式乘以 c可以再乘 1/c 變回來
列加上另一列的倍數Ri ← Ri + cRj把第 j 條的 c 倍加到第 i 條可以再減 cRj 變回來

三種運算都是可逆的，所以運算前後的方程組有完全相同的解集合，稱為 Row Equivalent（列等價）。注意第二種一定要 c ≠ 0：乘以 0 會把一條方程式整個抹掉，資訊就消失了。

列梯形與簡化列梯形

消去的目標是把矩陣化成「階梯」的樣子。每一列從左邊數來第一個不是 0 的數叫 Pivot（樞軸、領頭元素）。

  • Row Echelon Form（列梯形，REF）：(1) 全是 0 的列放在最下面；(2) 每一列的 pivot 都在上一列 pivot 的右邊；所以 pivot 下方全是 0，像一個往右下走的階梯。
  • Reduced Row Echelon Form（簡化列梯形，RREF）：在 REF 之外再要求 (3) 每個 pivot 都是 1；(4) pivot 所在的那一行，上下其他位置都是 0。

一個矩陣的 REF 不唯一（列運算的順序不同，數字會不同），但 RREF 是唯一的。所以 pivot 的位置和個數是矩陣本身的性質，pivot 的個數就叫做 Rank（秩）。

判斷題常考「這個矩陣是不是 RREF」：檢查零列在最下面、pivot 往右下排、pivot 都是 1、pivot 那一行其他位置全是 0，四個條件缺一不可。

高斯消去法：化成 REF 再回代

高斯消去法分兩個階段：

  1. 前進消去（forward elimination）：從第一行開始，選一個非零的數當 pivot（如果那個位置是 0，就和下面的列交換），再用「列加上倍數」把 pivot 下方的數全部消成 0。然後移到下一列、下一行重複。
  2. 回代（back substitution）：化成上三角之後，最後一條方程式只剩一個未知數，直接算出來；再往上一列代入，依序解出全部。

例子：x + y + z = 6，2x − y + z = 3，x + 2y − z = 2

步驟列運算結果
1R2 ← R2 − 2R1、R3 ← R3 − R1[1 1 1 | 6]、[0 −3 −1 | −9]、[0 1 −2 | −4]
2R3 ← R3 + (1/3)R2[0 0 −7/3 | −7]，化成 REF
3回代：−(7/3)z = −7z = 3
4−3y − z = −9 → −3y = −6y = 2
5x + y + z = 6 → x = 6 − 2 − 3x = 1

答案 (x, y, z) = (1, 2, 3)，代回原式三條都成立。

看程式碼：高斯消去法（前進消去＋回代）
forwardElim()：化成 REF
#define MAXR 8
#define MAXC 9
#define EPS 1e-9
double a[MAXR][MAXC];                          /* 增廣矩陣 [A | b] */
int m, n;                                      /* m 列；n 行（含最後一行常數 b） */

void swapRows(int r1, int r2) {
  for (int j = 0; j < n; j++) { double t = a[r1][j]; a[r1][j] = a[r2][j]; a[r2][j] = t; }
}

int forwardElim(void) {                        /* 回傳 pivot 個數；假設方陣且有唯一解時才回代 */
  int r = 0;
  for (int c = 0; c < n - 1 && r < m; c++) {
    int p = r;
    while (p < m && fabs(a[p][c]) < EPS) p++;  /* 往下找第一個非零的當 pivot */
    if (p == m) continue;                      /* 這一行都是 0：沒有 pivot */
    swapRows(r, p);
    for (int i = r + 1; i < m; i++) {          /* 只消去 pivot 下面的列 */
      double f = a[i][c] / a[r][c];
      for (int j = c; j < n; j++) a[i][j] -= f * a[r][j];
    }
    r++;
  }
  return r;
}
backSub()：由下往上回代
void backSub(double x[]) {                     /* 上三角（n-1 個未知數）由下往上回代 */
  int k = n - 1;
  for (int i = k - 1; i >= 0; i--) {
    double s = a[i][k];
    for (int j = i + 1; j < k; j++) s -= a[i][j] * x[j];
    x[i] = s / a[i][i];
  }
}

Gauss–Jordan 消去法：一路化到 RREF

Gauss–Jordan Elimination（高斯–喬登消去法）不回代，而是在消去時就把 pivot 化成 1、並且把 pivot 上面和下面都消成 0，一路化到 RREF。每處理完一行，那一行就只剩 pivot 的 1。上一節的例子繼續做下去：R2 除以 −3，再用它消掉 R1 和 R3 的第二行；R3 除以 −7/3，再消掉上面兩列的第三行，最後得到 [1 0 0 | 1]、[0 1 0 | 2]、[0 0 1 | 3]，答案直接寫在常數行。

Gauss–Jordan 每一步都很規律，適合手算判斷題和程式實作，也是求反矩陣的標準方法（對 [A | I] 做 Gauss–Jordan，左邊變成 I 時右邊就是 A−1）。代價是運算量比較多，下一節比較。

看程式碼：rref()：Gauss–Jordan 化成 RREF
rref()：Gauss–Jordan 化成 RREF
int rref(int pivotCol[]) {                     /* 回傳 rank；pivotCol[k] 是第 k 個 pivot 所在的行 */
  int r = 0;
  for (int c = 0; c < n && r < m; c++) {
    int p = r;
    while (p < m && fabs(a[p][c]) < EPS) p++;  /* 往下找第一個非零的當 pivot */
    if (p == m) continue;                      /* 這一行沒有 pivot：對應自由變數 */
    if (p != r) swapRows(r, p);                /* 列交換：把 pivot 換到第 r 列 */
    double piv = a[r][c];
    for (int j = 0; j < n; j++) a[r][j] /= piv;   /* 列乘以常數：pivot 變成 1 */
    for (int i = 0; i < m; i++)                /* 列相加：把同一行其他列消成 0 */
      if (i != r && fabs(a[i][c]) > EPS) {
        double f = a[i][c];
        for (int j = 0; j < n; j++) a[i][j] -= f * a[r][j];
      }
    pivotCol[r++] = c;
  }
  return r;
}

下面的動畫用的就是這個 rref()。動畫用分數精確計算，所以會看到 −7/3 而不是 −2.333，和手算一樣。

從 RREF 判斷解的情況

化成 RREF（或 REF）之後，只要看 pivot 落在哪些行就能判斷，不需要真的解出來。設有 n 個未知數、係數矩陣 A 的 rank 為 r：

  • 無解：某一列變成 [0 0 … 0 | c] 且 c ≠ 0，代表 0 = c 的矛盾。等價的說法是 pivot 落在常數行，或 rank(A) < rank([A | b])。
  • 唯一解：沒有矛盾，而且每個未知數那一行都有 pivot，也就是 r = n。
  • 無限多解：沒有矛盾，但 r < n。沒有 pivot 的行對應的未知數是 Free Variable（自由變數），可以任意取值，共有 n − r 個；有 pivot 的叫 basic variable，用自由變數表示出來。

齊次方程組

右邊全是 0 的 Ax = 0 叫 Homogeneous System（齊次方程組）。它一定有解 x = 0（trivial solution），常數行永遠是 0，不可能出現矛盾，所以只有「唯一解（只有零解）」和「無限多解」兩種。特別是：方程式比未知數少（m < n）時，一定有非零解，因為 rank 最多是 m < n，至少有 n − m 個自由變數。

看程式碼：classify()：判斷解的情況
classify()：判斷解的情況
/* 0 = 無解，1 = 唯一解，2 = 無限多解 */
int classify(int rank, int pivotCol[]) {
  if (rank > 0 && pivotCol[rank - 1] == n - 1) return 0;   /* pivot 落在常數行：出現 0 = 1 */
  if (rank == n - 1) return 1;                 /* 每個未知數都有 pivot */
  return 2;                                    /* 有沒有 pivot 的行：自由變數 */
}

運算量與數值問題

以 n 條方程式、n 個未知數為例，計算需要幾次乘法和除法（加減法的次數同級）：

方法乘除法次數n = 100 時
高斯消去法＋回代n³/3 + n² − n/3343,300 次
Gauss–Jordann³/2 + n²/2505,000 次，約多 47%

兩者都是 O(n³)，差別在最高次項的係數：Gauss–Jordan 要把 pivot 上方也消掉，每一行都要處理全部 n 列，而高斯消去法越往下需要處理的列越少。所以電腦解方程組通常用高斯消去法（或它的矩陣版本 LU 分解），Gauss–Jordan 多用在手算、求反矩陣與判斷題。

實際用浮點數計算時，還有一個問題：如果 pivot 很接近 0，除下去會把誤差放大。常見做法是 Partial Pivoting（部分樞軸選取）：每次在同一行中挑絕對值最大的數當 pivot。手算考題通常用「第一個非零的數」就好，本頁的程式和動畫也是這樣做。

易錯點

  • pivot 是 1 就是 RREF → 還要 pivot 那一行上下都是 0、零列在最下面、pivot 往右下排 例題
  • 有一列全是 0 就代表無限多解 → 零列只是多餘的方程式；要看 rank 是否小於未知數個數，還要先確定沒有 0 = c 的矛盾列 例題
  • det(A) = 0 就是無解 → det(A) = 0 只代表「不是唯一解」，可能無解也可能無限多解，要代回去用列運算判斷 例題
  • 齊次方程組可能無解 → x = 0 一定是解；未知數比方程式多時一定有無限多解 例題
  • 列運算可以乘以 0、或把一列換成兩列的和而不保留原列 → 三種列運算都必須可逆：乘的常數不能是 0，Ri ← Ri + cRj 時 Rj 本身不能被改掉 例題
