Elementary Matrices and Inverses 基本矩陣與反矩陣每個列運算都是左乘一個基本矩陣，把 [A | I] 化成 [I | A⁻¹]

Ch1 Matrices and Systems of Equations 難度 inverse elementary matrix Gauss–Jordan nonsingular

為什麼需要反矩陣

解一元一次方程式 3x = 6 時，我們會兩邊同乘 3 的倒數 1/3，得到 x = 2。倒數的關鍵性質是 (1/3)·3 = 1，乘上去就把係數「抵銷」掉。方程組寫成矩陣形式 Ax = b 之後，很自然會想問：有沒有一個矩陣能扮演 A 的「倒數」，讓我們兩邊左乘它就得到 x？

這個矩陣就是 Inverse Matrix（反矩陣） A−1。有了它，Ax = b 的解可以直接寫成 x = A−1b，而且這個公式對每一個 b 都成立，等於一次把「所有右邊常數」的情況都解決了。

不過矩陣和數字有兩個很大的差別：第一，數字只有 0 沒有倒數，但很多不是零矩陣的矩陣也沒有反矩陣；第二，矩陣乘法不能交換，所以「左乘」和「右乘」要分清楚。這一頁要回答三件事：

  • 什麼樣的矩陣有反矩陣？要怎麼判斷？（答案是一長串等價條件，考試最愛出判斷題）
  • 怎麼求反矩陣？（用 [A | I] 做列運算，背後的道理是 Elementary Matrix（基本矩陣））
  • 解方程組時，先求反矩陣划不划算？（通常不划算，後面會算給你看）

三種列運算、REF／RREF 和 Gauss–Jordan 消去法在 Gaussian Elimination 高斯消去法與列梯形 已經講過，這裡只簡短帶過，重點放在「把列運算寫成矩陣」之後能推出的東西。

反矩陣的定義與基本性質

定義：n×n 矩陣 A，如果存在 n×n 矩陣 B 使得 AB = BA = I，就說 A 是 Invertible（可逆的），也叫 Nonsingular（非奇異），B 稱為 A 的反矩陣，記作 A−1。找不到這樣的 B 就叫 Singular（奇異、不可逆）。

幾個要特別注意的地方：

  • 只有方陣才談反矩陣。2×3 的矩陣可能有「左反」或「右反」，但不會有同時滿足兩邊的反矩陣。
  • 定義要求兩邊都成立，但對方陣來說，只要 AB = I 一邊成立，BA = I 就自動成立（等價條件那一節會證明）。考試寫證明時可以用，但要知道它是定理，不是定義。
  • 不是零矩陣也可能不可逆：例如 [1 2; 2 4]，第二列是第一列的 2 倍，後面會看到這種矩陣一定不可逆。

反矩陣是唯一的

假設 B 和 C 都是 A 的反矩陣，那麼 B = BI = B(AC) = (BA)C = IC = C。關鍵只用到矩陣乘法的結合律，所以 A−1 這個寫法才有意義：可逆矩陣的反矩陣只有一個。

常用性質

性質（A、B 都是 n×n 可逆）為什麼
(A−1)−1 = AA−1A = AA−1 = I，換個角度看就是 A 是 A−1 的反矩陣
(AB)−1 = B−1A−1（順序顛倒）(AB)(B−1A−1) = A(BB−1)A−1 = AA−1 = I，另一邊同理
(AT)−1 = (A−1)TAT(A−1)T = (A−1A)T = IT = I，用的是 (XY)T = YTXT
(cA)−1 = (1/c)A−1，c ≠ 0(cA)((1/c)A−1) = (c/c)AA−1 = I
(Ak)−1 = (A−1)k(AB)−1 的規則重複用 k 次

(AB)−1 = B−1A−1 可以用「先穿襪子再穿鞋」來記：AB 是先做 B 再做 A（對向量 x 來說 ABx 是先乘 B），要還原就得先脫鞋（A−1）再脫襪子（B−1），寫成矩陣就是 B−1A−1。因為矩陣乘法不能交換，A−1B−1 一般來說是錯的（已用程式對本頁的兩個 3×3 例子驗證，兩者確實不相等）。推廣到多個：(A1A2⋯Ak)−1 = Ak−1⋯A2−1A1−1。

沒有「(A + B)−1 = A−1 + B−1」這種性質，甚至 A、B 都可逆時 A + B 也可能不可逆：取 B = −A，A + B 是零矩陣。

基本矩陣：把列運算寫成矩陣

三種基本列運算是：列交換、列乘以非零常數、列加上另一列的倍數（詳細見 增廣矩陣與三種列運算）。對單位矩陣 I 做一次基本列運算得到的矩陣，就叫做基本矩陣。所以基本矩陣也分三型：

型對 I 做的列運算長相反矩陣行列式
第 1 型Ri ↔ RjI 的第 i、j 列對調自己（再換一次就回來）−1
第 2 型Ri ← cRi，c ≠ 0I 的 (i, i) 換成 c(i, i) 換成 1/cc
第 3 型Ri ← Ri + cRj，i ≠ jI 的 (i, j) 放 c(i, j) 改成 −c1

判斷題常考「這是不是基本矩陣」：它必須恰好是 I 做一次列運算的結果。像 diag(2, 3) 要兩次第 2 型才做得出來，就不是基本矩陣；把 (i, i) 換成 0 也不是，因為乘以 0 不是合法的列運算。行列式那一欄是之後學行列式時會用到的事實，先記著：三型分別讓行列式乘上 −1、c、1。

關鍵性質：左乘 E 就是做列運算

如果 E 是對 I 做某個列運算得到的基本矩陣，那麼對任意 n×m 矩陣 A，EA 就等於對 A 做同一個列運算。原因是矩陣乘法「列的觀點」：EA 的第 i 列 = (E 的第 i 列) 乘以 A，也就是 A 各列的線性組合，係數就是 E 第 i 列的數字。E 只有改過的那一列不是 ei，其他列都和 I 一樣，所以 EA 只有那一列被改，其他列照抄 A。

反過來，右乘 E（AE）做的是行運算：例如右乘第 3 型 E（(i, j) 放 c），是把第 i 行的 c 倍加到第 j 行，方向和列運算剛好相反，考試偶爾會考這個陷阱。

有了這個性質，「對 A 依序做 k 次列運算」就可以寫成一個乘積 Ek⋯E2E1A。注意先做的在右邊，因為最靠近 A 的 E1 最先作用。

看程式碼：三型基本矩陣
elemSwap() / elemScale() / elemAdd()：對 I 做一次列運算
void identity(Frac E[MAXN][MAXN]) {
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) E[i][j] = frac(i == j, 1);
}
void elemSwap(Frac E[MAXN][MAXN], int i, int j) {          /* 第 1 型：R_i ↔ R_j */
  identity(E);
  E[i][i] = E[j][j] = frac(0, 1);
  E[i][j] = E[j][i] = frac(1, 1);
}
void elemScale(Frac E[MAXN][MAXN], int i, Frac c) {        /* 第 2 型：R_i ← cR_i（c ≠ 0） */
  identity(E);
  E[i][i] = c;
}
void elemAdd(Frac E[MAXN][MAXN], int i, int j, Frac c) {   /* 第 3 型：R_i ← R_i + cR_j */
  identity(E);
  E[i][j] = c;
}

用 [A | I] 求反矩陣

做法

把 A 和同樣大小的單位矩陣並排，組成 n×2n 的 [A | I]，然後對整列做 Gauss–Jordan 消去：每一行找 pivot、把 pivot 化成 1、再把同一行其他位置消成 0。如果左半能變成 I，右半就是 A−1：

[ A | I ]  ── 列運算 ──→  [ I | A⁻¹ ]

為什麼這樣做是對的

假設總共用了 k 次列運算把 A 化成 I，每一次對應一個基本矩陣，所以

E_k ⋯ E_2 E_1 A = I    ⇒    E_k ⋯ E_2 E_1 = A⁻¹

（右式由左式兩邊右乘 A−1 得到；或者說 P = Ek⋯E1 滿足 PA = I，方陣一邊成立就夠。）右半一開始是 I，跟著左半做了完全相同的 k 次列運算，結果就是 Ek⋯E1I = Ek⋯E1 = A−1。換句話說，右半就像一本「帳簿」，把所有基本矩陣的乘積記下來了。

這也說明了一件事：只能用列運算，不能混用行運算。行運算是右乘基本矩陣，混在一起就不再是 P·A 的形式，右半就不是 A−1了。

例子：A = [1 2 0; 2 5 1; 0 1 3]

步驟列運算（基本矩陣型）做完後的 [左半 | 右半]
0起點[1 2 0 | 1 0 0]、[2 5 1 | 0 1 0]、[0 1 3 | 0 0 1]
1R2 ← R2 − 2R1（第 3 型）R2 = [0 1 1 | −2 1 0]，第 1 行完成
2R1 ← R1 − 2R2（第 3 型）R1 = [1 0 −2 | 5 −2 0]
3R3 ← R3 − R2（第 3 型）R3 = [0 0 2 | 2 −1 1]，第 2 行完成
4R3 ← (1/2)R3（第 2 型）R3 = [0 0 1 | 1 −1/2 1/2]
5R1 ← R1 + 2R3（第 3 型）R1 = [1 0 0 | 7 −3 1]
6R2 ← R2 − R3（第 3 型）R2 = [0 1 0 | −3 3/2 −1/2]，左半變成 I

所以 A−1 = [7 −3 1; −3 3/2 −1/2; 1 −1/2 1/2]。驗算第一列乘第一行：1·7 + 2·(−3) + 0·1 = 1；第一列乘第二行：1·(−3) + 2·(3/2) + 0 = 0，都對得上 I（程式已驗證 AA−1 和 A−1A 都等於 I，也驗證了 6 個基本矩陣的乘積 E6⋯E1 恰好等於 A−1）。這 6 步也代表 A 可以寫成 A = E1−1E2−1⋯E6−1，是 6 個基本矩陣的乘積。

手算時養成習慣：算完一定挑一兩個位置驗算 AA−1。分數一多很容易抄錯，驗算只要 n 次乘法就能抓到錯誤。

看程式碼：inverse()：Gauss–Jordan 求反矩陣（精確分數）
inverse()：[A | I] → [I | A⁻¹]
#define MAXN 4
Frac aug[MAXN][2 * MAXN];                      /* 增廣矩陣 [A | I]，左半 n 行、右半 n 行 */
int n;

void swapRows(int r1, int r2) {
  for (int j = 0; j < 2 * n; j++) { Frac t = aug[r1][j]; aug[r1][j] = aug[r2][j]; aug[r2][j] = t; }
}

int inverse(Frac A[MAXN][MAXN], Frac inv[MAXN][MAXN]) {   /* 可逆回傳 1，不可逆回傳 0 */
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) {
      aug[i][j] = A[i][j];                     /* 左半放 A */
      aug[i][n + j] = frac(i == j, 1);         /* 右半放單位矩陣 I */
    }
  int r = 0;
  for (int c = 0; c < n; c++) {
    int p = r;
    while (p < n && isZero(aug[p][c])) p++;    /* 往下找第一個非零的當 pivot */
    if (p == n) continue;                      /* 這一行沒有 pivot：A 不可逆 */
    if (p != r) swapRows(r, p);                /* 第 1 型：列交換 */
    Frac piv = aug[r][c];
    for (int j = 0; j < 2 * n; j++) aug[r][j] = fdiv(aug[r][j], piv);   /* 第 2 型：pivot 變成 1 */
    for (int i = 0; i < n; i++)                /* 第 3 型：同一行其他列消成 0 */
      if (i != r && !isZero(aug[i][c])) {
        Frac f = aug[i][c];
        for (int j = 0; j < 2 * n; j++) aug[i][j] = fsub(aug[i][j], fmul(f, aug[r][j]));
      }
    r++;
  }
  if (r < n) return 0;                         /* pivot 不到 n 個：左半最後會有零列 */
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) inv[i][j] = aug[i][n + j];   /* 右半就是 A⁻¹ */
  return 1;
}
Frac：分子分母都是整數，隨時約分
typedef struct { long long n, d; } Frac;

long long gcdll(long long a, long long b) {
  if (a < 0) a = -a;
  if (b < 0) b = -b;
  while (b) { long long t = a % b; a = b; b = t; }
  return a ? a : 1;
}

Frac frac(long long n, long long d) {          /* 建立分數並約分 */
  if (d < 0) { n = -n; d = -d; }
  long long g = gcdll(n, d);
  Frac f = { n / g, d / g };
  return f;
}
Frac fadd(Frac x, Frac y) { return frac(x.n * y.d + y.n * x.d, x.d * y.d); }
Frac fsub(Frac x, Frac y) { return frac(x.n * y.d - y.n * x.d, x.d * y.d); }
Frac fmul(Frac x, Frac y) { return frac(x.n * y.n, x.d * y.d); }
Frac fdiv(Frac x, Frac y) { return frac(x.n * y.d, x.d * y.n); }   /* 呼叫前要確定 y 不是 0 */
int isZero(Frac x) { return x.n == 0; }
int isOne(Frac x) { return x.n == 1 && x.d == 1; }
matMul() / isIdentity()：驗證乘起來是 I
void matMul(Frac X[MAXN][MAXN], Frac Y[MAXN][MAXN], Frac Z[MAXN][MAXN]) {
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) {
      Frac s = frac(0, 1);
      for (int k = 0; k < n; k++) s = fadd(s, fmul(X[i][k], Y[k][j]));
      Z[i][j] = s;
    }
}

int isIdentity(Frac Z[MAXN][MAXN]) {
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
      if (Z[i][j].n != (i == j) || Z[i][j].d != 1) return 0;
  return 1;
}

下面的動畫跑的就是這個 inverse()。每做一次列運算，右上角會畫出對應的基本矩陣 E，下方寫出它是第幾型；最後一步把右半標成綠色，就是 A−1。

不可逆時會發生什麼

如果 A 不可逆，[A | I] 的左半不可能化成 I。在 Gauss–Jordan 的過程中，你會在某一行往下找不到非零的 pivot；繼續把其他行做完，左半最後一定會出現全是 0 的列。這時候就可以停手，宣告 A 不可逆，不需要再算右半。

為什麼零列代表不可逆？如果 A 可逆，那麼 PA 也可逆（P 是基本矩陣的乘積，可逆矩陣相乘還是可逆），但一個有零列的矩陣 PA 乘上任何矩陣 B，(PA)B 的那一列還是 0，不可能等於 I，矛盾。

右半那一列也很有意思：零列 = (右半那一列的係數) 乘上 A 的各列，也就是說右半記錄了「A 的哪幾列組合起來會變成 0」。圖 3 的例子讀出 R3 = R1 + R2，確實 (1, 2, 3) + (2, 1, 4) = (3, 3, 7)，A 的列線性相依（程式已驗證這個係數向量 y 滿足 yA = 0）。

手算時一旦看到兩列成比例、某一列是其他列的組合，或某一行（左半）全部是 0，就可以直接說 A 不可逆。

可逆的等價條件

線性代數最重要的定理之一：對 n×n 矩陣 A，下面這些敘述全部等價（一個成立，全部成立）。考研的是非題、選擇題很大一部分都在考這張表。

  1. A 可逆。
  2. Ax = 0 只有零解（trivial solution）。
  3. A 列等價於 I（A 的 RREF 是 I），也就是 A 有 n 個 pivot、rank A = n。
  4. A 可以寫成基本矩陣的乘積。
  5. 對每一個 b，Ax = b 都有唯一解。
  6. 存在 B 使 AB = I（只要右反）；或存在 C 使 CA = I（只要左反）。
  7. det A ≠ 0（行列式那一章會證明）。

證明的骨架：(1) ⇒ (2) ⇒ (3) ⇒ (4) ⇒ (1)

  • (1) ⇒ (2)：若 Ax = 0，兩邊左乘 A−1 得 x = A−10 = 0。
  • (2) ⇒ (3)：Ax = 0 只有零解，代表化簡後沒有自由變數，每一行都有 pivot；方陣有 n 個 pivot，RREF 只能是 I。
  • (3) ⇒ (4)：A 列等價於 I，表示 Ek⋯E1A = I。基本矩陣都可逆，所以 A = E1−1⋯Ek−1，而 Ei−1 也是基本矩陣。
  • (4) ⇒ (1)：基本矩陣都可逆，可逆矩陣的乘積還是可逆。

(5) 和 (1) 的關係：A 可逆時 x = A−1b 就是解，而且若 Ax = Ay，則 A(x − y) = 0，由 (2) 得 x = y，所以唯一。反過來，若每個 b 都有唯一解，取 b = 0 就得到 (2)。

只要一邊：AB = I 就夠了

設 A、B 都是 n×n 而且 AB = I。看 Bx = 0：兩邊左乘 A 得 x = ABx = A0 = 0，所以 Bx = 0 只有零解，由 (2) ⇒ (1) 知 B 可逆。於是 A = A(BB−1) = (AB)B−1 = B−1，所以 A 可逆、反矩陣就是 B，而且 BA = BB−1 = I。這個結論只對方陣成立；非方陣可能有一邊的反矩陣卻沒有另一邊。

不可逆的常見訊號

  • 有一列（或一行）全是 0，或兩列（兩行）成比例。
  • 某一列是其他列的線性組合（列線性相依）。
  • 找得到非零的 x 使 Ax = 0，例如各行加起來是零向量，就取 x = (1, 1, …, 1)。
  • A2 = 0 這類條件：若 A 可逆，左乘 A−1 得 A = 0，矛盾（n ≥ 1 時零矩陣不可逆）。

2×2 反矩陣公式

2×2 的情況太常用，值得直接背公式。對 A = [a b; c d]，令 det A = ad − bc：

A⁻¹ = 1/(ad − bc) · [  d  −b ]        （ad − bc ≠ 0 時才有）
                     [ −c   a ]

口訣是「主對角對調、副對角變號、除以 ad − bc」。推導可以直接驗算：[a b; c d]·[d −b; −c a] = [ad − bc, 0; 0, ad − bc] = (ad − bc)I，所以除以 ad − bc 就得到 I。ad − bc = 0 時兩列成比例，A 不可逆。

例：A = [3 1; 5 2]，ad − bc = 6 − 5 = 1，所以 A−1 = [2 −1; −5 3]。驗算 3·2 + 1·(−5) = 1、3·(−1) + 1·3 = 0，正確（程式也確認這個公式和 Gauss–Jordan 算出來的一樣）。

3×3 以上也有類似的公式 A−1 = adj(A)/det A（伴隨矩陣），在行列式那一章介紹；但手算 3×3 時，[A | I] 通常比較快也比較不容易錯。

看程式碼：inverse2()：2×2 公式
inverse2()：交換對角、非對角變號、除以 det
int inverse2(Frac A[MAXN][MAXN], Frac inv[MAXN][MAXN]) {
  Frac det = fsub(fmul(A[0][0], A[1][1]), fmul(A[0][1], A[1][0]));   /* ad − bc */
  if (isZero(det)) return 0;
  inv[0][0] = fdiv(A[1][1], det);
  inv[0][1] = fdiv(frac(-A[0][1].n, A[0][1].d), det);
  inv[1][0] = fdiv(frac(-A[1][0].n, A[1][0].d), det);
  inv[1][1] = fdiv(A[0][0], det);
  return 1;
}

用反矩陣解方程組划算嗎

x = A−1b 寫起來很漂亮，但真的計算時，先求反矩陣幾乎都比直接消去慢。以 n×n、算乘除法次數為例：

做法乘除法次數n = 10n = 100
高斯消去＋回代（解一次）n³/3 + n² − n/3430343,300
先求 A−1，再算 A−1bn³ + n²1,1001,010,000，約是消去法的 2.9 倍

求反矩陣的 n³ 是這樣來的：處理第 k 行時，pivot 那一列真正需要更新的位置是「左半 pivot 右邊的 n − k 格」加上「右半已經不是 0 的 k 格」（其餘右半位置還是 I 的 0），一共 n 格；除以 pivot 要 n 次，其他 n − 1 列各要 n 次乘法，所以每一行 n² 次，n 行就是 n³（程式逐格計數，n = 10、100 時都剛好是 n³）。這已經利用了右半的零；如果傻傻地每次都更新整列 2n 格，會變成約 2n³。

就算要解很多個右邊 b，也有更好的做法：把消去過程記下來（也就是之後的 LU 分解），分解一次約 n³/3，之後每個 b 只要 n² 次，比求反矩陣省下大約 2n³/3。除此之外，浮點數計算時，先算 A−1 再相乘的捨入誤差通常也比直接消去大。

那反矩陣什麼時候有用？(1) 理論推導與證明，例如 x = A−1b 說明解唯一、(AB)−1 的公式；(2) 2×2 這種公式一眼就寫得出來的小矩陣；(3) 真的需要 A−1 本身的時候，例如題目問 A−1 的某個元素、或要算 A−1B 這類式子。

看程式碼：countInverseOps()：求反矩陣的乘除法次數
countInverseOps()：利用右半 I 的零結構計數
long long countInverseOps(long long size) {
  long long cnt = 0;
  for (long long k = 0; k < size; k++) {
    long long live = (size - k - 1) + (k + 1);   /* 左半 pivot 右邊的格子 + 右半已經非零的 k+1 行 */
    cnt += live;                                 /* 第 2 型：整列除以 pivot */
    cnt += (size - 1) * live;                    /* 第 3 型：其他 n−1 列各做一次 */
  }
  return cnt;
}

考研重點：題型地圖

題型常見度解題步驟例題
求 3×3 反矩陣很常考寫 [A | I]，逐行 Gauss–Jordan；算完挑幾個位置驗算 AA−1 = I例題
含參數 k：何時可逆、求反矩陣很常考化簡到最後一個 pivot 含 k（或算 det），令它為 0 找出不可逆的 k；其餘 k 代入求 A−1例題
反矩陣性質的是非題常考(AB)−1 順序顛倒、轉置與反矩陣可交換、和沒有公式；找反例用 B = −A 或對角矩陣例題
可逆的等價條件、證明常考從「Ax = 0 只有零解」切入最好用；方陣只需一邊的反矩陣例題
寫成基本矩陣的乘積常考記下化成 I 的每一步 Ei，A = E1−1E2−1⋯Ek−1（順序和做的順序相同）例題
辨認基本矩陣、2×2 公式偶爾基本矩陣恰好是 I 做一次列運算；2×2 主對角對調、副對角變號、除以 ad − bc例題 例題
運算量比較偶爾求反矩陣約 n³，消去法約 n³/3，多個 b 時分解一次再每個 n²例題

易錯點

  • (AB)−1 = A−1B−1 → 順序要顛倒：(AB)−1 = B−1A−1；(A + B)−1 則沒有公式，A + B 甚至可能不可逆 例題
  • 第 3 型基本矩陣的反矩陣是它自己，或把 c 改成 1/c → 第 3 型的反矩陣是把 c 變號（−c）；改成 1/c 的是第 2 型，反矩陣是自己的是第 1 型 例題
  • 2×2 公式是把 b、c 對調 → 對調的是主對角 a、d，b、c 只變號，最後除以 ad − bc 例題
  • 對角線上有兩個數不是 1 也算基本矩陣 → 基本矩陣只能和 I 差「一次」列運算；diag(2, 3) 是兩個基本矩陣的乘積 例題
  • E3E2E1A = I，所以 A = E3E2E1 → E3E2E1 是 A−1；A = E1−1E2−1E3−1，每個都要取反矩陣、順序也要反過來 例題
  • 證明 A 可逆一定要同時驗證 AB = I 和 BA = I → 方陣只要一邊成立就夠，但這是需要證明的定理（用 Bx = 0 只有零解）；非方陣不適用 例題
  • [A | I] 左半化不成 I 時，換個順序再試或做行運算 → 只要某一行找不到 pivot、左半出現零列，A 就不可逆；中途做行運算會讓右半不再是 A−1 例題
  • 解 Ax = b 先求 A−1 最快 → 求反矩陣約 n³，是消去法 n³/3 的 3 倍；多個 b 也是分解一次再逐個代入比較省 例題
